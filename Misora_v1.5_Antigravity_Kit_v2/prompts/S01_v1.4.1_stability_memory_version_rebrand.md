### A. Stability & Memory Remediation (Highest Priority — P1/P2)
1. **`BUG-01` — Per-Job Search Cancellation & Cancellation-Aware Bounded Queue (`misora.py`, `core/search_engine.py`):**
   - Replace the shared mutable boolean `self.search_cancel_flag` race with a per-job `threading.Event` (`self._search_cancel_event`) captured by the worker closure so starting Search B NEVER reactivates a cancelled Search A. Keep `self.search_cancel_flag` as a synchronized backward-compatible attribute if existing tests inspect it, while the worker always checks `job_cancel_event.is_set()`.
   - Give `self.search_queue` a **finite capacity** (e.g., `maxsize=2048`) and make queue submission **cancellation-aware** (helper `_put_queue_cancellable(q, item, cancel_event)` looping `q.put(item, timeout=0.05)` and aborting immediately if `cancel_event.is_set()` on `queue.Full` — a producer MUST NEVER block forever when the UI stops polling and the queue is full).
   - Enforce cancellation checks across ALL 5 stages:
     1. Outer `os.walk()` traversal in `core/search_engine.py:search_directory()`,
     2. Directory & file iteration loop,
     3. Individual file scanning boundaries (and before loading each bundle/text file),
     4. Queue submission (`progress`, `batch`, `finished`),
     5. Application shutdown (`_on_root_destroy()` and `destroy()`).

2. **`BUG-02` & `BONUS-02` — Bounded MTL Concurrency + Finite Pending Backpressure + Shared SSL (`misora.py`, `core/mtl_engine.py`):**
   - In `core/mtl_engine.py`, cache ONE thread-safe module-level SSL context via `_get_shared_ssl_context()` instead of calling `ssl.create_default_context()` per `MTLEngine.__init__()` (eliminating Windows OS root cert store reload spikes).
   - Remember: a bare `ThreadPoolExecutor(max_workers=3)` bounds concurrently running workers ONLY — it does NOT bound queued Futures submitted in a 500-box loop! Implement **BOTH** bounded workers (e.g., `max_workers=3`) **AND** finite pending-work backpressure (e.g., a single lightweight producer/dispatcher thread feeding a bounded `queue.Queue(maxsize=16)` or `threading.Semaphore(12)` gate, so the Tk UI thread NEVER blocks and pending queued tasks remain strictly bounded even on a 1,000-box story). Explicitly document behavior when the pending queue is full (dispatcher waits cooperatively with cancel check on a background thread; never blocks Tk).
   - Require all of the following for `All Script` `Translate All`:
     - Per-batch `threading.Event` cancellation token,
     - Automatic cancellation of pending work on **document close, engine switch, or application shutdown**,
     - Cooperative cancellation checked between every request,
     - Request timeout handling (`cfg.timeout_sec`),
     - Strict stale-result rejection after close/reload/box-change,
     - Respect for `cfg.rate_limit_delay` between network requests,
     - ZERO Tkinter calls from any worker/dispatcher thread (`Rule 15`).
   - **Honest Cancellation Guarantee:** Document explicitly in `PROJECT_STATE.md` and code comments that an already-running blocking `urllib` socket call cannot always be forcefully killed mid-flight; cancellation is cooperative (pending queued items abort immediately, no new requests start, and any late in-flight reply is discarded by identity/cancel guards on arrival).
   - Keep `translate_async()` signature 100% backward compatible for existing callers and tests.

3. **`BUG-03` & `BONUS-01` — Complete Document-Scoped Cache Pruning & Anti-Repopulation (`misora.py`, `core/xunity_sync.py`):**
   - Add `_prune_document_caches(self, file_path: Optional[Path], doc: Optional[Any])` invoked in `close_file()`, `_close_all_documents_without_prompt()`, and `open_file(..., reload_from_disk=True)` (before replacing the prior entry).
   - Prune ALL document-scoped state for the closed/reloaded document:
     - `self._mtl_all_results`, `self._mtl_all_statuses`, `self._mtl_all_errors`, `self._mtl_all_req_seqs`,
     - `self._mtl_all_selected_uid`, `self._mtl_all_last_ctx`, `self._mtl_all_block_ranges` (reset when matching the closed/reloaded doc),
     - Per-UID request/application sequence maps (`self._latest_applied_mtl_seq`, and reset `self._mtl_drawer_active_context` / stale `self._mtl_drawer_latest_seq` when active doc closes/reloads),
     - `self.sync_manager.jp_source_cache` via a safe **per-UID** `XUnitySyncManager.unregister_jp_keys(uids)` method (NEVER blindly wipe unrelated open documents with a global clear).
   - **Prevent Late Repopulation:** In `_poll_mtl_drawer_queue()` and `_poll_mtl_queue()`, verify the document is still open/active AND its batch/doc generation matches BEFORE inserting anything into `_mtl_all_results/statuses/errors` so late worker completions can NEVER repopulate pruned state of a closed or replaced document.

4. **`BUG-04` — Ownership-Safe UnityPy `env` Disposal (`core/bundle_io.py`):**
   - In `load_bundle_story()`, once `env = get_unitypy().load(raw_bundle_bytes)` succeeds, wrap TextAsset discovery, extraction, and `StoryDocument.from_binary()` in `try ... except Exception: dispose_unity_env(env); raise` so EVERY failure path before ownership transfer disposes `env`, while successful calls transfer ownership intact without disposing the live `env`.

5. **`BUG-05` — Idempotent, Producer-Safe `MisoraLogger.close()` (`core/logger.py`):**
   - Add `self._stop_event = threading.Event()` and `self._closed: bool = False`.
   - Define explicit behavior for calls to `log()` after shutdown starts: once `self._closed` / `self._stop_event.is_set()` is True, `log()` MUST NOT enqueue to `_file_queue` or restart `_writer_thread` (it may still print to stdout/history safely without raising).
   - In `_file_writer_loop()`, read with `self._file_queue.get(timeout=0.1)` and exit cleanly when `self._stop_event.is_set()` and the queue is drained (or sentinel `None` is received) — a full queue can NEVER drop the stop signal.
   - Make `close()` idempotent: mark `_closed = True`, `flush(timeout=1.0)`, set `_stop_event.set()`, best-effort `put_nowait(None)` ignoring `queue.Full`, `join(timeout=1.0)`, and **only clear `self._writer_thread = None` if `not self._writer_thread.is_alive()`** (never drop the reference to a still-alive thread).

6. **`BUG-06` — Atomic `_is_saving` Guard Placement (`core/bundle_io.py`):**
   - Initialize `tmp_path: Optional[Path] = None` BEFORE `try:`. Move `out_path = Path(out_path)`, `out_path.parent.mkdir(parents=True, exist_ok=True)`, and `tmp_path = ...` **INSIDE `try:`**, guarding `if tmp_path is not None and tmp_path.exists():` in `finally:` so `_is_saving = False` ALWAYS executes even if `mkdir` or `tmp_path` init fails.

7. **`BONUS-03` — On-Demand Polling & Safe Elimination of Double Reload (`misora.py`):**
   - Run `_poll_mtl_queue()` and `_process_search_queue()` ONLY while work is in flight (start polling on dispatch; stop rescheduling when idle/finished).
   - In `_apply_delta(BulkFileDelta)`, eliminate the redundant `self.open_file(self.current_file_path, reload_from_disk=True)` ONLY AFTER ensuring the in-loop refresh demonstrably updates ALL required model, `env`/`obj`, `plain_text`, `dirty`, `_saved_state_checkpoints`, `_original_jp_by_uid`, `_locked_boxes`, and UI state (`_update_views()`, `_dirty_state_changed()`, `_sync_edit_menu_states()`).
