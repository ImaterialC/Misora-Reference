### B. Windows Terminal Console Visibility Toggle — Option B (`U02`, `4.3`)
- Implement native Win32 console visibility toggle (`Debug > Show / Hide Windows Console` + `F12`):
  - Use `ctypes.windll.kernel32.GetConsoleWindow()` to obtain `hwnd` (returns `0` on non-Windows or `pythonw.exe`).
  - **CRITICAL Win32 Visibility Rule:** `user32.ShowWindow()` returns the *previous* visibility state, NOT the new state! Query **`user32.IsWindowVisible(hwnd)`** BEFORE toggling:
    - If `hwnd == 0`: do NOT spawn a new OS process; show informative toast (`'No Windows Terminal console is attached to this process.'`) and keep menu unchecked/safe.
    - If `IsWindowVisible(hwnd)` is truthy -> call `ShowWindow(hwnd, SW_HIDE=0)` (now hidden); otherwise -> call `ShowWindow(hwnd, SW_SHOW=5)` (now visible). Sync menu checkbutton from the post-toggle visibility state (re-query `IsWindowVisible(hwnd)` or use exact intended boolean).
