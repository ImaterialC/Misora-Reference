### A. Pure-Python Lossless NGUI & Grapheme-Aware Auto Word Wrap Engine (`core/word_wrap.py`, `U07`)
**Context:** XUnity.AutoTranslator relies on runtime plugin word-wrap, so XUAT `.txt` translations are typically single unwrapped lines. Once imported into `.unity3d` story bundles (rendered natively without plugin wrap), lines overflow the game's `50d x 3` box.

Create `core/word_wrap.py` (ZERO Tkinter imports — accepts `measure_fn: Callable[[str], int]` and `safe_width: int` calibrated to constant `50d` `Nunito Bold`):
1. **Atomic Tokenization & Unicode Grapheme Safety:**
   - Tokenize preserving NGUI tags (`[b]`, `[/b]`, `[RRGGBB]`, `[-]`, `[rub:ruby]base[/rub]`, `<size=...>`, etc.) and placeholders (`{playername}`, `{0}`) as indivisible atomic units (tags measure `0px`; ruby measures its `base` text width; `{playername}`/`{N}` measures `'PlayerName'` proxy width).
   - **Unicode Grapheme Boundaries:** Group base characters with trailing combining marks (`unicodedata.category(c) in ('Mn', 'Mc', 'Me')`), variation selectors (`\uFE00-\uFE0F`), and ZWJ sequences (`\u200D`) as indivisible grapheme clusters so wrapping NEVER splits combining dakuten (e.g., `か\u3099`), accents, or emoji sequences across lines!
   - **Malformed / Incomplete Tags:** Treat unclosed `[FF0000` or stray `[rub:foo` safely as literal text without crashing or dropping characters.
   - **Intentional Whitespace:** Preserve intentional leading/trailing/multiple spaces on lines; collapse ONLY the single break-point space replaced by `\n`.
   - NEVER silently truncate content, emit CSIF headers (`@@...`), or create empty binary arguments.
2. **Wrapping Rules (EN & JP Aware):**
   - Preserve existing intentional `\n` breaks by default (`reflow_existing_breaks: bool = False` wraps only lines exceeding `safe_width`; optional `reflow_existing_breaks=True` reflows full paragraphs).
   - Latin/English: break cleanly at word/space boundaries; hard-break an indivisible single token at grapheme boundaries only if that single token alone exceeds `safe_width`.
   - CJK/Japanese (no spaces): break at grapheme boundaries with kinsoku rules (avoid starting a new line with closing punctuation `。、！？）」』…・` or ending a line with opening brackets `（「『`).
   - Return `WrapResult(wrapped_text, original_lines, new_lines, still_overflows_lines: bool, still_overflows_width: bool, changed: bool)` so callers report boxes still exceeding 3 lines without ever dropping words.
