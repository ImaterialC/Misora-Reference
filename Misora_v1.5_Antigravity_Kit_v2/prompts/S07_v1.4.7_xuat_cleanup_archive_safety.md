### A. Pure-Python Per-File Transactional XUAT Cleanup & Archival Engine (`core/xuat_cleanup.py`, `U01`)
Build `core/xuat_cleanup.py` with **STRICT pure-core separation** (ZERO Tkinter imports, ZERO imports from `misora.py`! Inject any backup-path generator callback `backup_path_fn: Optional[Callable[[Path, Path, str], Path]] = None` with a clean pure-Python collision-resistant default inside `core/xuat_cleanup.py`):

1. **Strict XUAT Parsing & Format Preservation:**
   - Reuse `read_text_file_strictly()`, `write_atomic_encoded()`, `split_xuat_line()`, and `normalize_xuat_key()`. NEVER decode with `errors='replace'` and rewrite.
   - Preserve exact encoding, BOM (`UTF-8 BOM`/`UTF-16`/`CP932`), line endings (`CRLF`/`LF`/`CR`), key whitespace, comments (`#`, `//`, `;`), regex directives (`r:`, `sr:`), unchanged lines, and line ordering. NEVER reject short Japanese keys.

2. **Stale Import Reference Guard (SHA-256 Fingerprint Verification):**
   - At import/preview time, capture `source_fingerprints: Dict[Path, str]` (SHA-256 hex digest of raw file bytes) for every referenced XUAT file.
   - Immediately before executing cleanup, re-hash every targeted XUAT file on disk and verify `actual_sha256 == expected_sha256`.
   - If ANY targeted source file changed on disk since import/preview, **ABORT** cleanup before modifying disk and return an actionable `StaleSourceError` requiring a fresh preview!

3. **Conservative, Auditable 3-Tier Classification (`CleanupCandidate`):**
   - `applied` (*Overwritten / Confirmed Applied*): exact `(file_path, line_number)` entries confirmed successfully applied in the completed `Import from XUAT` run (never skipped, locked, missing, or failed boxes).
   - `duplicate` (*Duplicate Key Occurrence*): additional occurrences sharing exact `normalize_xuat_key()` (NOT substring matching). Controlled by `duplicate_scope`: `'selected_only'` vs `'all_duplicates'`.
   - `already_translated_unique` (*Conservative Right-Side Match*): current asset raw text equals unescaped right-side XUAT translation value AND that value maps to **strictly 1 unique key** across the XUAT index AND meets safe length (`>= 6` non-space chars).
   - `uncertain` (*Ambiguous Right-Side Match*): short/common translations (e.g., `'Yes.'`) or values mapped by `>1` Japanese keys. **Default `selected=False`** — NEVER deleted unless explicitly checked by the user.

4. **Linebreak Policy (`linebreak_policy`):**
   - `'keep_blank_line'` — replace removed entry with an empty line, keeping physical line numbers intact.
   - `'remove_line_break'` (*Include the line break*) — remove the entire physical line including its newline.

5. **Mandatory Archival Backup Contract & Explicit Encoding Policy:**
   - **Mandatory by Default (No Conflicting Optional Checkbox):** Archival backup is **MANDATORY** for destructive cleanup removals by default. Unarchived removal is ONLY possible if the user deliberately enables an explicit advanced opt-out (`allow_unarchived_deletion`) AND confirms a **separate, clearly labeled irreversible-deletion confirmation dialog**.
   - **Two Strategies with Explicit Encoding Contracts:**
     - **`per_source_file`** (`<archive_dir>/<source_stem><ext>`): Preserves the source file's **original encoding, BOM, and newline style** byte-for-byte on creation/append (for single-source 1:1 fidelity).
     - **`combined`** (`<archive_dir>/xuat_removed_archive<ext>`): Uses a single **canonical UTF-8 (no BOM) with LF (`\n`)** representation because one plain text file cannot hold mixed raw CP932 + UTF-16 byte streams simultaneously; records each source file's exact original `encoding`, `bom`, and `newline` in the structured traceability header (`# [YYYY-MM-DD HH:MM:SS] op=<op_id> | source=<rel_or_name> | encoding=<enc> | bom=<true|false> | newline=<CRLF|LF|CR> | story=<story> | reason=<reason>`). Document clearly in `PROJECT_STATE.md` that per-file archives support raw byte-for-byte fidelity while combined archives preserve all decoded Unicode text + metadata reversibly under canonical UTF-8/LF.
   - **Target Validation & Default Exclusion:** Default directory `<SCRIPT_DIR>/backups/xuat_archive` (OUTSIDE `BepInEx\Translation\en\Text`), default extension **`.xuat.old`**. Refuse to write if any archive target resolves to the same path as a source file. Emit explicit warning via `validate_archive_target()` whenever `ext.lower() == '.txt'` OR `archive_dir` lies inside any active `BepInEx\Translation\en\Text` root.

6. **Explicit Per-File Transaction Boundaries & Archive-First Ordering:**
   - Multi-file cleanup is explicitly **atomic PER FILE** (do NOT describe it as a whole-batch OS filesystem transaction).
   - **Strict Execution Order:**
     1. Re-verify SHA-256 fingerprints of ALL target source files first (abort cleanly before any write if any file is stale).
     2. Write and verify **Archive Backup(s) FIRST** (same-dir `.tmp` -> verify -> `os.replace()`) BEFORE modifying any XUAT source file.
     3. For each source file: create optional per-file Safety Backup -> write modified content to same-dir `.tmp` -> reopen & strictly validate encoding/line structure -> `os.replace()`.
     4. If any source file fails mid-batch, preserve that file untouched/rolled back, stop cleanly, and return a granular `CleanupReport` enumerating exact file lists: `archived_files`, `modified_files`, `rolled_back_files`, `untouched_files`, `empty_files` (with exact safety backup path or `None`), and `errors`.
   - **Empty-File Check (`is_xuat_file_meaningfully_empty()`):** Comments (`#`, `//`, `;`), whitespace, and non-entry syntax do NOT count as meaningful entries. NEVER auto-delete inside the engine.
