### D. Lossless Native Paste Box (`Ctrl+Alt+V`) — Insert vs Replace (`core/story_ast.py`, `core/undo_journal.py`, `misora.py`, `4.1`, `AMD-05`)
- **Why `BoxEditDelta` is NOT sufficient:** `BoxSnapshot` carries 6 fields (`speaker`, `voice_cue`, `kind`, `seg_texts`, `raw_breaks`, `extra_args`), whereas `BoxEditDelta` does not preserve `voice_cue`, `kind`, `raw_breaks`, or `extra_args`. Replacing a box MUST NOT silently drop any snapshot field!
- **Core AST & Undo Journal Extensions (Narrowly Scoped):**
  1. In `core/story_ast.py`, add `StoryDocument.replace_box(self, box_index: int, snapshot: BoxSnapshot) -> BoxSnapshot`:
     - Replaces the box's owned record span (`_get_box_record_span(box)`) with records reconstructed losslessly from ALL 6 fields of `snapshot` (`speaker`, `voice_cue` via `cmd_id=12` `vo_...` when present, `kind` preserving `cmd_id=6`/`cmd_id=35` without ever merging adjacent narration boxes `QW-B01`, multi-segment `seg_texts`, `raw_breaks`, and per-segment `extra_args`).
     - Preserves surrounding interstitial commands and boundary breakers; returns the complete original `BoxSnapshot.from_box(old_box)` before mutation.
  2. In `core/undo_journal.py`, add `BoxSnapshotReplaceDelta`:
     ```python
     @dataclass
     class BoxSnapshotReplaceDelta:
         box_index: int
         old_snapshot: BoxSnapshot
         new_snapshot: BoxSnapshot
         file_path: str = ""
         box_uid: Optional[int] = None
         source: str = "box_replace"
     ```
     Export it from `core/__init__.py` and handle forward (`new_snapshot`) and reverse (`old_snapshot`) application cleanly inside `MisoraApp._apply_delta()`.
- **Transactional Validation & 3-Way Paste Chooser (`on_box_paste(self, confirm: bool = True, mode: Optional[str] = None)`):**
  - Stage and validate all target indices and replacement snapshots **BEFORE** mutating any record in `self.current_doc` so a failed or partially rejected paste NEVER leaves a partially corrupted document!
  - When `confirm=True` and `mode is None`, show a clear 3-option modal dialog:
    - **`Insert after Box #N`**: inserts `K` new boxes after cursor preserving full `BoxSnapshot`, recorded as ONE `BoxStructuralDelta`.
    - **`Replace Box #N..#M`**: overwrites eligible unlocked boxes starting at `current_box_idx`, strictly skipping locked targets (`is_box_locked()`) with a clear toast/status count, clamping/disclosing any excess blocks beyond document length deterministically, and recording ONE Undo batch of `BoxSnapshotReplaceDelta` entries.
    - **`Cancel`**: aborts with zero mutations.
  - Keep `on_box_paste(confirm=False)` backward-compatible (defaults to `mode='insert'`).
