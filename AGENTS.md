# Instructions for AI agents

This file applies to any AI assistant, coding agent, or automated reviewer working with this repository.

1. Read `README.md`, `docs/PROJECT_MANDATE.md`, `docs/WORKFLOW_RULES.md`, `docs/RESEARCH_AND_EVIDENCE.md`, and `docs/CURRENT_SESSION.md` before doing substantive work.
2. Follow only the phase document explicitly assigned by the owner. Do not skip ahead.
3. Treat `references/priconne-adv-tools/` and the original owner-supplied assets as read-only reference material unless the owner explicitly authorizes a change.
4. Do not assume a file exists because an older README, prior conversation, or another AI mentioned it. Inspect the current branch and report the exact path and commit.
5. Never invent file access, program behavior, test results, source locations, or consensus.
6. When reporting a technical defect, cite the exact repository, path, symbol/function, relevant line range or commit, reproduction conditions, expected behavior, actual behavior, and impact when available.
7. Keep technical reports, reusable council messages, and Antigravity prompts in English. Communicate with the owner in Bahasa Indonesia.
8. Do not expose secrets, personal data, live game databases, decrypted payloads, or private local files in this public repository.
9. Do not implement code during Phases 0–3. Phase 3 produces a plan and prompts only. Code execution belongs to Phase 4 after owner approval.
10. If evidence is missing or tool capability is insufficient, stop the affected claim and label it accurately. Ask the owner for the specific missing input.
