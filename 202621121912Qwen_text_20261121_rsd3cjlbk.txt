## A. CORRECTNESS / DATA (verified on local)
NEW-1 BOX-PASTE-UNDO-DELTA-DUPLICATION (P0/P1): on_box_paste records BoxStructuralDelta INSIDE the
  insert loop with constant box_index=ins_idx and snapshots=snaps_to_ins (full list) each iteration.
  N boxes -> N identical deltas each describing N insertions at ins_idx. Undo deletes N boxes N times
  (over-deletion/wrong boxes); redo inserts N*N. Fix: ONE delta outside the loop.
NEW-2 RIBBON-CONTINUOUS-HIDDEN-TARGET (P1): _insert_text_wrapper (ribbon B/I/U/Color/Grad/Ruby/Glossary)
  targets self.txt_continuous when Continuous View is on — but txt_continuous is pack_forget'd (hidden)
  in bundle card-stream mode. Ribbon edits the hidden fallback, not the active card -> no visible effect.
  Keyboard Ctrl+B/I/U uses _card_shortcut_wrap(w) correctly (inconsistent). on_insert_ruby + glossary
  insert also affected. Fix: target active card widget in continuous. Ledger CONTINUOUS-RIBBON-TARGET-STALE
  "resolved" is contradicted by _insert_text_wrapper still hardcoding txt_continuous.
NEW-3 F8-CROSS-FILE-STALE-APPLY (P0/P1): on_translate_current_box captures b_idx at request; update_ui
  checks only b_idx bounds, NOT file/doc identity. Switching files mid-translate applies the result to
  the NEW file's box at the same index. Fix: capture (file_path, box_uid), verify before apply.
NEW-4 BOX-CUT-NONCONTIGUOUS-UNDO-LOSS (P1): on_box_cut records one delete delta box_index=targets[0];
  undo restores contiguously (box_index+offset). Non-contiguous cut (e.g. 2 & 5) restores at 2 & 3.
  Fix: preserve original per-snapshot indices.
NEW-5 CLEAR-SKELETON-BYPASSES-LOCK (P1, D8): on_clear_dialogue_skeleton clears ALL boxes with no
  is_box_locked check. Fix: skip locked + report preserved count.
NEW-6 SEARCH-REENTRANT-DOUBLE-WORKER (P1): on_start_search has no running guard; search_entry and
  folder_path_entry bind <Return> directly, bypassing disabled btn_find. Return during an active search
  spawns a second worker, resets results, interleaves two queries in one queue. Fix: _search_running guard.
NEW-7 PLAINTEXT-CONTINUOUS-CUT-PASTE-NO-COMMIT (P2 conditional, Rule 11): txt_continuous <<Cut>>/<<Paste>>
  bound to no-op shims; plain-text fallback cut/paste never commits to model/journal (only KeyRelease
  flushes). Fix: explicit commit on virtual events for plain text.
NEW-8 SEARCH-CURRENT-PLAINTEXT-STALE (P2): mem_docs only includes entry["doc"] (None for plain text),
  so "Current File(s)" search reads disk and misses unsaved plain-text edits. Fix: include plain-text
  snapshot.

## B. EFFICIENCY / REDUNDANT

  update_idletasks auto-resize + char count. Typing lag on large stories. Fix: debounce raw/list/highlight.

NEW-13 PREFS-SAVE-ON-EVERY-UI-CHANGE (P3): _save_user_prefs (DPAPI + atomic write) fires on many small
  UI actions (spinbox/entry FocusOut, theme, scope). Fix: debounce / save only on change.
NEW-14 DEAD-NOOP-HELPERS (P3): _push_undo = pass; _on_continuous_* no-op shims still bound. Clean or wire.
