         EMPTY STATE DROPZONE & MULTI-SELECT FILE OPENING)
======================================================================

User Requirements:
1. On fresh launch, the Left Sidebar MUST default to the **`Open Project`** tab (NOT `Search Results`).
2. When `Open Project` is empty, display an **Empty State** with a large open button and clear description: *"No opened project — drag and drop `.unity3d` or datamine files here"*.
3. Current Open Project button only supports selecting **1 file**; upgrade it to support **multi-select** for opening multiple files at once.

### Audit of Edge Cases, Hidden Bugs & Efficiency Traps to Prevent
1. **O(N) Continuous-View Redraw Storm on Multi-Select (HIGH EFFICIENCY IMPACT):**
   - Naive `for fp in selected_files: self.open_file(fp)` would load, parse, and rebuild Continuous View cards `N` times in a row (known ~160 MB / high widget churn on big stories), freezing the UI when selecting 20–50 files.
   - **Recommended Architecture (Lazy Workspace Registration):**
     * Split file registration from active rendering: `_add_project_paths(paths, activate_first=True)` registers all valid selected paths into the `Open Project` list (deduplicating already-listed paths) with zero eager bundle parsing for inactive files, then loads & renders **only the first newly added file** (or keeps current active doc if desired).
     * Subsequent files lazy-load on click in the `Open Project` list.
     * Collect unreadable/unsupported paths and show **one** summary status/toast instead of `N` blocking modal error popups.
2. **Unified Open + Drag-and-Drop Pipeline (also cleanly addresses `FOLDER-DROP-EXTRA-IGNORED`):**
   - Switch single-file `filedialog.askopenfilename` -> `filedialog.askopenfilenames` with practical filters:
     `Supported Files (*.unity3d *.asset *.txt)` (default), `Unity3D Bundles (*.unity3d *.asset)`, `Text/Datamine Scripts (*.txt)`, `All Files (*.*)`.
   - Safely normalize Tkinter's return value (handle empty `""` / `()` on cancel, and `self.tk.splitlist(res)` if a raw Tcl string is returned).
   - Route both `Open Files` (multi-select), `Open Folder`, and Drag-and-Drop through the same `_add_project_paths()` pipeline.
3. **Empty State Overlay Lifecycle & DnD Trap:**
   - **DnD Trap:** Placing an Empty State `Frame`/`Label`/`Button` over the file list can silently block `tkinterdnd2` drops unless the Empty State widgets also register/forward the drop target! Must explicitly bind drop target + verify drop works directly onto the Empty State panel.
   - **Bidirectional Transitions:**
     * 0 files at launch -> show Empty State on `Open Project` tab.
     * 1+ files added -> hide Empty State, display file list.
     * User closes the last open file (`close_file`) -> automatically re-display Empty State!
   - **Compact Secondary Action:** Include a large primary **`Open Files...`** (multi-select) button plus a smaller secondary **`Open Folder...`** button right underneath so folder/datamine workflows are 1 click away without hunting menus.
   - **Theme & Narrow-Width Safety:** Wrap Empty State description dynamically to sidebar width and wire into theme-refresh (`best_contrast_fg`, Rule 21).
4. **Default Tab & Auto-Switch Discipline:**
   - Default left notebook tab at startup = `Open Project` (always, whether empty or restoring session).
   - Switch to `Search Results` ONLY when the user actively initiates a search.
5. **High-Value, Low-Complexity QoL Innovations (Optional / Lean):**
   - **Quick Filename Filter Entry** above the `Open Project` list (pure in-memory substring filter — huge QoL for Priconne's hundreds of numeric `storydata_*.unity3d` files; <25 lines of code).
   - **Per-File Dirty Marker (`*`) + Count Badge** (`Open Project (N)`) tied to `N16` per-file dirty tracking.
