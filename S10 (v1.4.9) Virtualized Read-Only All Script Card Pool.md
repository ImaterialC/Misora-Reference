### 2. `U-15`, `U-17`, `U-20`, `U-04` — Virtualized Read-Only Card Pool (`misora.py`)
Replace S03 Technique A single-`tk.Text` rendering with a **Virtualized Read-Only Card Pool**:

- **Dynamic Viewport Pool Sizing:**
  - Calculate pool capacity dynamically from `ceil(viewport_height / card_slot_height) + overscan` (recomputed on viewport resize; NEVER hardcode a fixed pool of 12–15 cards).
  - Virtual scroll canvas/scrollbar maps total logical document height (`Box 0 block + N dialogue card slots`). Scrolling rebinds existing pool card widgets to newly visible indices — zero per-box widget creation/destruction during scroll, and zero per-box Pillow image generation (`get_all_script_card_*`, `get_all_script_dotted_rule_image`, `get_voice_badge_image` removed from All Script render path).
- **Widget Recycling & Identity Safety:**
  - Each pooled card stores `card.bound_box_idx` and `card.bound_box_uid` updated atomically on rebind.
  - All click/checkbox/lock/scroll bindings resolve dynamically through `card.bound_box_idx` / `card.bound_box_uid` so recycled cards NEVER display stale text or mutate the wrong box.
  - Select Box and Translation Lock visual indicators read/write authoritative document sets so states survive recycling cleanly.
  - On recycle to a different box, reset the card's internal scroll view (`yview_moveto(0.0)`, `xview_moveto(0.0)`) so no previous box's internal scroll offset bleeds onto another box.
- **Box 0 Metadata Block (`U-17`, `U-18`):**
  - Render Box 0 at the top as a separate full-width, auto-wrapped metadata/synopsis block (`Title`, `Subtitle`, full `Synopsis`).
  - NEVER force Box 0 into the `54d × 3` dialogue card clipping geometry and NEVER apply red overflow markers to Box 0.
- **Ordinary Dialogue Card Layout & Pixel-Exact `54d` Geometry (`U-20`):**
  - **Header (authoritative per `Expectasi2.png` + Voice Cue clarification):**
    `[ ]  🔓  ◆  [BOX #NNN]  Speaker  ♪ vo_adv_...  [N segs]`
    * **KEEP** inline `♪` symbol and voice cue identifier text (`vo_adv_...`) whenever `box.voice_cue` is present; NEVER delete or alter `box.voice_cue` in `StoryDocument` AST.
    * **REMOVE** the round blue speaker badge image (`get_voice_badge_image`) completely from All Script headers.
    * **NO dashed `----------` separator lines** anywhere in the card.
    * Reserve a fixed-width Select Box slot so toggling Select Box never shifts the Lock icon or header horizontally.
  - **Body (Pixel-Exact `54d × 3` Read-Only Box):**
    * **NEVER rely on `tk.Text(width=54)`** for horizontal calibration. Compute exact container/body pixel width from the shared S09 `54d` measurement helper (accounting explicitly for border width and internal padding) and enforce it via pixel container sizing (`pack_propagate(False)` / `grid_propagate(False)` or Canvas window width) across BOTH `Global — Nunito Bold` and `Japanese` font presets.
    * Fixed visual height of **3 lines** (`height=3`, `wrap="none"`), strictly read-only.
    * **ZERO red overflow markers** in All Script (red markers exist in Dialogue Editor only).
    * Lines 4+ stay clipped inside the fixed 3-line height (no visible scrollbar; full text always preserved in AST); horizontal text >54d clips cleanly inside the constant box width.
- **Non-Conflicting Internal Card Scrolling Contract (Required Gesture Separation):**
  - **Outer All Script list scrolling:** Plain `<MouseWheel>` anywhere inside the All Script viewport (including when cursor is over a card body) ALWAYS scrolls the **outer All Script list** smoothly.
  - **Active/Hovered card internal scrolling (4+ line cards, no visible scrollbar):**
    * `Shift+<MouseWheel>` over a card body scrolls that card's internal text vertically (`yview_scroll`) and returns `"break"` so the outer list does NOT move.
    * When a read-only card body is focused/selected, `<Up>`, `<Down>`, `<Prior>` (`PageUp`), and `<Next>` (`PageDown`) scroll its internal lines when content exceeds 3 lines (returning `"break"`), without scrolling the outer list.
- **Active Box Highlight (`U-04`):**
  - Clicking/selecting a box applies a high-contrast active card background tint, distinct accent border, and header marker (`▶ [BOX #NNN]`) updated in-place on the old and new visible cards ONLY (visually distinct from both the Select Box checkbox state and Translation Lock state).

### 3. `U-03` — Segment-Aware `Quick Edit` Tab (`misora.py`)
- Add a **`Quick Edit`** tab directly beside **`Raw Commands`** in the bottom pane (preserve the exact locked `"Raw Commands"` tab label).
- **Visibility & Lazy Sync:**
  - Automatically select the `Quick Edit` tab when switching into `All Script` mode.
  - Keep `Quick Edit` available in `Dialogue` mode (both Preview OFF and Preview ON) with **lazy sync** (zero extra widget updates while `Raw Commands` is the active bottom tab).
  - When `Dialogue Preview` is ON and `Quick Edit` is active, typing in `Quick Edit` updates the active box via the canonical model path and live-refreshes the read-only `Dialogue Preview` capsule (keeping `txt_dialogue_preview` strictly read-only and excluded from save paths).
- **Plain Surface:** No ruler, no character counter, no red overflow markers, no NGUI rich-text preview effects inside `Quick Edit`.
- **Segment-Aware Lossless Architecture (CRITICAL — `core/story_ast.py` `Box.clean_text` concatenates segments without a delimiter):**
  - **Single-segment Box (`len(box.segs) <= 1`):** Render ONE simple plain `tk.Text` editor.
  - **Multi-segment Box (`len(box.segs) > 1`):** Expose each segment (`Seg 1`, `Seg 2`, ..., `Seg K`) as its own compact plain editable `tk.Text` row inside the scrollable `Quick Edit` tab — NEVER flatten multi-segment boxes into one string!
  - All segment edits commit as **ONE logical Box transaction**, preserving exact segment ownership/ordering and all `BoxSnapshot` fields (`speaker`, `voice_cue`, `kind`, `seg_texts`, `raw_breaks`, `extra_args`), recording complete old/new `BoxSnapshot` state for Undo/Redo.
- **In-Place UI Sync & Safety:**
  - Bind `Quick Edit` to the active box via stable **`box.uid`** (not merely positional index).
  - Keystrokes in `Quick Edit` MUST patch **ONLY** the bound visible All Script card in-place (NEVER calling `_render_continuous_view()` or rebuilding the card pool on every keystroke!).
  - Flush pending `Quick Edit` changes cleanly before changing active box, switching views, switching documents, closing document, or saving.
  - Enforce **Translation Lock** at the model/application mutation layer (disable/read-only `Quick Edit` widgets and reject mutation when active box is locked).
  - Never mutate immutable JP source keys (`_original_jp_by_uid`, `sync_manager.jp_source_cache`) or write drafts into `.misora`.
