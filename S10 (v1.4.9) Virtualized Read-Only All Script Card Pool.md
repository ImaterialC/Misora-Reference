### 2. `U-15`, `U-17`, `U-20`, `U-04` — Virtualized Read-Only Card Pool (`misora.py`)
Replace S03 Technique A single-`tk.Text` rendering with a **Virtualized Read-Only Card Pool**:

- **Dynamic Viewport Pool Sizing:**
  - Calculate pool capacity dynamically from `ceil(viewport_height / card_slot_height) + overscan` (recomputed on viewport resize; NEVER hardcode a fixed pool of 12–15 cards).
  - Virtual scroll canvas/scrollbar maps total logical document height (`Box 0 block + N dialogue card slots`). Scrolling rebinds existing pool card widgets to newly visible indices — zero per-box widget creation/destruction during scroll, and zero per-box Pillow image generation (`get_all_script_card_*`, `get_all_script_dotted_rule_image`, `get_voice_badge_image` removed from All Script render path).
- **Widget Recycling & Identity Safety:**
  - Each pooled card stores `card.bound_box_idx` and `card.bound_box_uid` updated atomically on rebind.
  - All click/checkbox/lock/scroll bindings resolve dynamically through `card.bound_box_idx` / `card.bound_box_uid` so recycled cards NEVER display stale text or mutate the wrong box.
  - Select Box and Translation Lock visual indicators read/write authoritative document sets so states survive recycling cleanly.
  - On recycle to a different box, reset the card's internal scroll view (`yview_moveto(0.0)`, `xview_moveto(0.0)`) so no previous box's internal scroll offset bleeds onto another box.
- **Box 0 Metadata Block (`U-17`, `U-18`):**
  - Render Box 0 at the top as a separate full-width, auto-wrapped metadata/synopsis block (`Title`, `Subtitle`, full `Synopsis`).
  - NEVER force Box 0 into the `54d × 3` dialogue card clipping geometry and NEVER apply red overflow markers to Box 0.
- **Ordinary Dialogue Card Layout & Pixel-Exact `54d` Reference Geometry (`U-20`):**
  - **Header (authoritative per `Expectasi2.png` + Voice Cue clarification):**
    `[ ]  🔓  ◆  [BOX #NNN]  Speaker  ♪ vo_adv_...  [N segs]`
    * **KEEP** inline `♪` symbol and voice cue identifier text (`vo_adv_...`) whenever `box.voice_cue` is present; NEVER delete or alter `box.voice_cue` in `StoryDocument` AST.
    * **REMOVE** the round blue speaker badge image (`get_voice_badge_image`) completely from All Script headers.
    * **NO dashed `----------` separator lines** anywhere in the card.
    * Reserve a fixed-width Select Box slot so toggling Select Box never shifts the Lock icon or header horizontally.
  - **Body (Pixel-Exact `54d × 3` Read-Only Box):**
    * **NEVER rely on `tk.Text(width=54)`** for horizontal calibration. Compute exact container/body pixel width from the canonical S09 `54d` reference pixel helper (Nunito Bold 54-digit reference width, accounting explicitly for border width and internal padding) and enforce it via pixel container sizing (`pack_propagate(False)` / `grid_propagate(False)` or Canvas window width) so container width stays identical across `Global — Nunito Bold` and `Japanese` presets.
    * Fixed visual height of **3 lines** (`height=3`, `wrap="none"`), strictly read-only.
    * **ZERO red overflow markers** in All Script (red markers exist in Dialogue Editor only).
    * Lines 4+ stay clipped inside the fixed 3-line height (no visible scrollbar; full text always preserved in AST); horizontal text >54d clips cleanly inside the constant box width.
- **Non-Conflicting Internal Card Scrolling Contract (Required Gesture Separation):**
  - **Outer All Script list scrolling:** Plain `<MouseWheel>` anywhere inside the All Script viewport (including when cursor is over a card body) ALWAYS scrolls the **outer All Script list** smoothly.
  - **Active/Hovered card internal scrolling (4+ line cards, no visible scrollbar):**
    * `Shift+<MouseWheel>` over a card body scrolls that card's internal text vertically (`yview_scroll`) and returns `"break"` so the outer list does NOT move.
    * When a read-only card body is focused/selected, `<Up>`, `<Down>`, `<Prior>` (`PageUp`), and `<Next>` (`PageDown`) scroll its internal lines when content exceeds 3 lines (returning `"break"`), without scrolling the outer list.
- **Active Box Highlight (`U-04`):**
  - Clicking/selecting a box applies a high-contrast active card background tint, distinct accent border, and header marker (`▶ [BOX #NNN]`) updated in-place on the old and new visible cards ONLY (visually distinct from both the Select Box checkbox state and Translation Lock state).

### 3. `U-03` — `raw_breaks`-Safe Segment-Aware `Quick Edit` Tab & View-Aware Live Sync (`misora.py`)
- Add a **`Quick Edit`** tab directly beside **`Raw Commands`** in the bottom pane (preserve the exact locked `"Raw Commands"` tab label).
- **Plain Surface:** No ruler, no character counter, no red overflow markers, no NGUI rich-text preview effects inside `Quick Edit`.
- **View-Aware Visibility & Surface Update Contract:**
  - **All Script mode:** Auto-select `Quick Edit` when entering All Script. Typing in `Quick Edit` patches **ONLY** the active visible Virtualized Card in-place (NEVER calling `_render_continuous_view()` or rebuilding the All Script pool per keystroke).
  - **Dialogue mode, Preview OFF:** Keep `Quick Edit` available; typing refreshes the visible Dialogue Editor state as required without rebuilding All Script.
  - **Dialogue mode, Preview ON:** Typing in `Quick Edit` updates the read-only `Dialogue Preview` capsule live (keeping `txt_dialogue_preview` strictly read-only and excluded from save paths).
  - **Raw Commands active:** Avoid unnecessary `Quick Edit` widget updates while the `Raw Commands` tab is active, unless flushing a required pending edit on tab switch.
- **CRITICAL — `raw_breaks`-Safe Multi-Segment Snapshot Construction (Data Integrity Guard):**
  Because `BoxSnapshot.from_box()` stores each segment's `Seg.raw` into `raw_breaks` and `StoryDocument._records_from_snapshot()` uses `raw_breaks[k]` as the record text for non-linebreak values, mutating `seg_texts` while retaining stale `raw_breaks` WOULD silently write old segment text back into `StoryDocument.records`.
  Implement the exact segment-edit lifecycle using existing canonical `core/story_ast.py` APIs (or STOP per Part 0 Rule 3 if existing APIs cannot support it safely):
  1. **Session Start:** When a Box editing session begins in `Quick Edit`, capture ONE complete original `BoxSnapshot.from_box(box)` (`old_snapshot`) bound to stable **`box.uid`**.
  2. **Separate Segment Buffers:**
     - Single-segment Box (`len(box.segs) <= 1`): expose ONE plain `tk.Text` editor.
     - Multi-segment Box (`len(box.segs) > 1`): expose EACH segment (`Seg 1`, `Seg 2`, ..., `Seg K`) as its own compact plain editable `tk.Text` row inside the scrollable `Quick Edit` tab — NEVER flatten multi-segment boxes into one string.
  3. **Live Model & View Update:** Collect edited text separately for each segment and update the live `StoryDocument` through existing canonical lossless AST APIs so `StoryDocument.records` ALWAYS contain the actual edited segment text while preserving `raw_breaks`, `Seg.raw`, exact segment count/ordering, `speaker`, `voice_cue`, `kind`, and all `extra_args`. Update ONLY the active visible surface per the View-Aware contract above.
  4. **One Logical Undo Transaction (NO Per-Keypress Undo Spam):** Do NOT create a separate Undo transaction on every keypress or in every segment editor. Record **ONE complete old/new `BoxSnapshot` delta** (`old_snapshot` captured at session start -> fresh `new_snapshot = BoxSnapshot.from_box(updated_box)` containing updated `seg_texts` AND updated `raw_breaks`) when the edit session commits or is flushed.
  5. **Mandatory Flush Points:** Flush any pending `Quick Edit` session BEFORE Box navigation, view/mode switch, bottom-tab switch, document switch, document close, and save.
- **Translation Lock Parity — Mandatory S09b Contract:**
  Quick Edit MUST follow the exact established Manual Dialogue typing lock policy documented in the live-verified S09b Translation Lock Operation Matrix.
  - Do NOT impose a blanket disabled/read-only state on Quick Edit solely because the active Box is locked.
  - Do NOT reject Quick Edit mutations merely because the Box is locked unless the S09b matrix confirms that ordinary Manual Dialogue typing is also blocked under the same conditions.
  - Preserve all operation-specific Translation Lock guards. Quick Edit must not weaken, bypass, or broaden those guards.
  - Keep Translation Lock and Speaker Pin strictly independent.
  - If the S09b Translation Lock Matrix is unavailable or has not been verified against the live source, STOP and request Project Lead review. Do not invent a new Lock policy.
- **Immutability:** Never mutate immutable JP source keys (`_original_jp_by_uid`, `sync_manager.jp_source_cache`) or write drafts into `.misora`.
