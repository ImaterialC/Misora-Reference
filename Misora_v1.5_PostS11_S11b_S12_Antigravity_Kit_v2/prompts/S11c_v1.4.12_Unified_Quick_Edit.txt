PART 2 — EXACT TECHNICAL SPECIFICATIONS (`Q-22` ONLY)
==================================================

### 1. Unified Single-Box Quick Edit Surface (`misora.py`)
Replace S10's multi-textbox per-segment splitting in `_rebuild_quick_edit_widgets()` with **ONE single unified plain `tk.Text` box** for the entire active Box (matching the main Dialogue Editor's single-box editing UX, minus ruler, red overflow markers, NGUI decorators, and preview styling):
- **Canonical Text Projection (`core/story_ast.py::Box.clean_text`):**
  - `Box.text` joins existing `Seg.text` values (`"".join(s.text for s in self.segs if s.text)`), and `Box.clean_text` returns `game_to_xuat(self.text)`.
  - Populate the single Quick Edit `tk.Text` using the **exact existing `box.clean_text` projection** used by the main Dialogue Editor (`txt_dialogue`). Do NOT independently reconstruct segment text.
  - Display an optional non-blocking info badge (e.g., `[N segs]`) when `len(box.segs) > 1`.
  - Box 0 (`is_box0_active`) or plain text (`current_doc is None`): preserve read-only info label (never call `inject_box` on Box 0).
- **Compatibility for Existing References:** Maintain a clear single-element attribute/property (or update all call sites including `tests/test_v15_s08_release_gate_stress.py::_qe_seg_widgets[0]`) so no stress benchmark or internal helper breaks on the unified widget.

### 2. Mandatory 8 Data-Integrity, Undo/Redo & Lock Invariants
1. **Pre-First-Mutation Snapshot Timing:** Capture complete `old_snapshot = BoxSnapshot.from_box(box)` (full `seg_texts`, `raw_breaks`, `extra_args`, `speaker`, `voice_cue`, `kind`) **strictly BEFORE the first live mutation** when a Quick Edit session starts — NEVER after edits begin or at commit time.
2. **Canonical Mutation Path:** While typing in Quick Edit, mutate via canonical **`self.current_doc.inject_box(idx, None, new_tx)` WITHOUT `seg_texts`** (exact same text distribution path as the main Dialogue Editor).
3. **Fresh Post-Mutation Snapshot:** On commit/flush, capture fresh `new_snapshot = BoxSnapshot.from_box(updated_box)` from the actually updated AST into **ONE logical `BoxSnapshotReplaceDelta`** Undo transaction (zero per-keypress Undo spam).
4. **Lossless Original Multi-Segment Undo:** Undo (`StoryDocument.replace_box()`) MUST restore the **exact original multi-segment split** (`seg_texts`, `raw_breaks`, `extra_args`, `speaker`, `voice_cue`, `kind`).
5. **Exact Redo:** Redo MUST restore the exact edited state.
6. **Binary Round-Trip:** `to_binary()` -> `from_binary()` MUST pass verbatim on edited, undone, and redone states, with `StoryDocument.records` directly verified (no stale `raw_breaks`).
7. **Immutable JP Keys & Lock UID Survival:** `_original_jp_by_uid`, `sync_manager.jp_source_cache`, `_modified_box_uids`, and `_locked_box_uids` MUST survive Edit, Undo, and Redo cleanly.
8. **S09b Translation Lock Parity (Row 1 — Mandatory):**
   - Quick Edit MUST follow the live-verified S09b Translation Lock Operation Matrix Row 1 (**`ALLOWED`** — identical to Manual Dialogue typing).
   - Do NOT impose a blanket disabled/read-only state on Quick Edit solely because the active Box is locked.
   - Preserve all operation-specific Lock guards (speaker rename, Paste Replace, Cut Box, MTL Apply, Auto Word Wrap, Clear Skeleton, XUAT Import) and strict Pin ⊥ Lock independence.

### 3. Preserved View-Aware Live Sync & Mandatory Flush Points
- **All Script mode:** Patch ONLY the active visible Virtualized Card in-place (`0` calls to `_render_continuous_view()`).
- **Dialogue mode, Preview OFF:** Update `txt_dialogue` in-place without feedback loop (`edit_modified(False)`).
- **Dialogue mode, Preview ON:** Update read-only `Dialogue Preview` capsule live (with zero red overflow blocks per S11b `Q-23`).
- **Raw Commands active:** Skip unnecessary Quick Edit rebuilds until switching back.
- **Flush Points:** Flush pending Quick Edit session before navigation, view/mode switch, bottom-tab switch, raw edit entry, doc switch/close, revert, save, undo/redo (`Ctrl+Z`/`Ctrl+Y`), and structural box mutations.
