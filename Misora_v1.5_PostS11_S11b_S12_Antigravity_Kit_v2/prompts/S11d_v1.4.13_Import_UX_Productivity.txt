PART 2 — EXACT TECHNICAL SPECIFICATIONS (S11d)
==================================================

### 1. `Q-06` (`U-22`) — MouseWheel Propagation Everywhere in `ImportFromXUATDialog` (`misora.py`)
- Ensure `<MouseWheel>` scrolls the `ImportFromXUATDialog` review canvas smoothly regardless of which child widget sits beneath the mouse pointer — explicitly covering ALL static labels, section headers, frames, checkboxes, and status text (`Story Speaker`, `Story Metadata`, `Actor`, `No XUAT Match`, `Skip`, `XUAT Actor Match`, provenance labels, buttons, etc.).
- Cleanly unbind/scope mousewheel handlers when the dialog closes or loses focus so main-window scrolling is never hijacked after dialog close.

### 2. `Q-07` (`U-23`) — Per-Group Tri-State Select All Headers in `ImportFromXUATDialog` (`misora.py`)
- Add a group-level `Select All` control above EACH of the 3 review groups:
  1. **Metadata** (Title, Subtitle, Synopsis),
  2. **Unique Actors**,
  3. **Dialogue**.
- **Accurate None / Some / All Tri-State Semantics:**
  - Toggling the group control selects/deselects (un-skips/skips) all eligible (matched, unlocked) rows in that group only.
  - Whenever an individual row's `Skip` checkbox changes, recompute the group header state accurately across all 3 states: **None** (`[ ]`), **Some / Partial** (`[-]` / indeterminate visual indicator), and **All** (`[✓]`) — NEVER show a misleading checked state when only a subset is selected.
  - Locked rows remain auto-skipped and unaffected.

### 3. `Q-08` (`U-24`) — Multi-Line Synopsis Metadata Import Including Empty Existing Synopsis (`misora.py`, `core/xuat_cleanup.py`)
- Add a **Synopsis (`summary`)** row to `ImportFromXUATDialog`'s Metadata section alongside Title and Subtitle.
- **Empty Existing Synopsis Requirement (CRITICAL):**
  - The Synopsis import row MUST be available whenever a valid XUAT Synopsis candidate exists (or when existing Box 0 `summary` is non-empty), **EVEN IF the current document's Box 0 `summary` is empty** — so users can populate previously empty Synopsis metadata, not merely overwrite existing text. (Verify in `/plan` how the Synopsis JP source key is obtained when `summary` is empty vs non-empty, e.g., original JP metadata cache / Box 0 raw record / matched key.)
- **Multi-Line Wrapped Layout:**
  - Render Synopsis in a comfortable **multi-line `wrap="word"`** paired read-only container (e.g., 4–6 lines with internal scroll if longer). **NEVER force Synopsis into a 1-line `54d` box** like Title and Subtitle.
- **Full Transactional Parity:**
  - Include `◀ 1/N ▶` duplicate switcher, provenance `filename:line`, and `Skip` checkbox (when skipped, existing Box 0 `summary` stays untouched).
  - Apply via `doc.set_metadata(title=..., subtitle=..., summary=...)` recorded in **`MetadataDelta`** inside the single atomic Import Undo batch (with full Undo/Redo and mid-operation rollback parity + Document Identity Guard).
  - Include applied non-speaker Synopsis `AppliedXuatRecord` in post-import `XUAT Translation Archiving` when `Archive the XUAT translation` is checked.

### 4. `Q-09` (`U-25`) — Remove Leftover Archiving Sub-Header (`misora.py`)
- Inspect `XuatCleanupDialog` and remove/replace the leftover sub-header text `"Import Complete - XUAT translation Archiving"` (and any similar `"Import Complete - ..."` remnants) with clean consistent **`"XUAT Translation Archiving"`** branding.

### 5. `Q-10` (`u-19`) — `Select All Box` Button & Checkbutton (`misora.py`)
- Add a **`Select All Box`** button and checkbutton integrated cleanly with existing `Select Box` mode (`self._selected_boxes`).
- **Strict Safety Rules:**
  - Selects/deselects **dialogue boxes ONLY** (`0 .. len(doc.boxes) - 1`).
  - **Box 0 (`-1`) MUST ALWAYS be excluded** (never added to `_selected_boxes`).
  - **Translation Lock MUST remain 100% unchanged** when toggling Select All Box (strict selection ⊥ lock independence).
  - Sync visual `[x]`/`[ ]` checkboxes cleanly in both Dialogue view and All Script Virtualized Card Pool (surviving card recycling).

### 6. `Q-11` (`u-3`) — Safe MTL Globe (`🌐`) Button Per Engine Card (`misora.py`)
- Add a compact Globe (`🌐`) button on each MTL engine card in the right MTL drawer.
- **Safe Default Behavior (Zero Unverified Deep-Link Claims):**
  - Clicking `🌐` copies the active Box's dialogue text cleanly to the system clipboard (with a clear toast e.g., `"Copied active box text to clipboard — opened <Engine Name>"`) and opens that provider's official web translator URL via `webbrowser.open(...)`.
  - Do **NOT** fabricate unverified URL query prefill parameters or claim a provider supports URL text prefill unless verified and explicitly approved by the Project Lead.
  - Handle empty/Box 0 text gracefully.

### 7. `Q-12` (`u-16`) — Episode `Title (Subtitle)` in Window Title Bar (`misora.py`)
- Update the main window title bar format to:
  `Misora: Story Editor - <filename><dirty*> — <Title> (<Subtitle>)` (omitting `(<Subtitle>)` if subtitle is empty, and omitting `— ...` if both title and subtitle are empty).
- **Zero Disk Re-Read:** Read strictly from already-parsed `current_doc.get_metadata()` in memory (zero disk I/O or re-parsing).
- **Safe Truncation:** Truncate combined `Title (Subtitle)` cleanly with ellipsis (`…`) beyond ~65 characters so Windows title bar / taskbar stays neat.
- Refresh window title automatically on open, tab switch, Box 0 metadata edit, `Import from XUAT` metadata apply, Undo/Redo of `MetadataDelta`, and close.
- **NEVER alter the `"Dialogue"` / `"All Script"` top header label.**
