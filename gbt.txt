# **2. Temuan teknis paling penting**

## **S11b — XUAT Scanner**

Ini bagian yang paling perlu diperbaiki.

**Temuan pertama:&#x20;**`by_norm_key`**&#x20;tidak terdapat dalam source code saat ini.**

Saya menemukan struktur yang sebenarnya di `core/xuat_index.py`:

- `_norm_stripped_map`
- `_norm_exact_map`
- `normalize_xuat_key()`
- `lookup_all_by_norm_key()`

V5 sudah mengarahkan kita untuk menggunakan normalisasi canonical yang ada. Prompt S11b seharusnya mengikuti struktur tersebut, bukan meminta implementasi menggunakan `by_norm_key` yang belum tersedia.

Referensi: [core/xuat_index.py](https://github.com/ImaterialC/Misora-Editor/blob/main/core/xuat_index.py?utm_source=chatgpt.com#L225-L259).

**Temuan kedua: resolver saat ini belum benar-benar membatasi pemindaian hanya ke&#x20;**`Translation\en\Text`**.**

Saya menemukan tiga jalur yang berpotensi melewati batas:

1. File `.txt` dapat diterima langsung tanpa memastikan lokasinya berada di `Translation\en\Text`.
2. Setiap direktori bernama `Text` dapat diterima sebagai root eksplisit.
3. Jalur `p / "Text"` memungkinkan pemilihan folder bahasa lain, misalnya `Translation\ja\Text`.

Referensi: [resolve_xuat_text_roots()](https://github.com/ImaterialC/Misora-Editor/blob/main/core/xuat_index.py?utm_source=chatgpt.com#L134-L181).

Ini bukan sekadar masalah dokumentasi. Prompt S11b harus meminta perbaikan resolver dan pengujian negatif untuk kondisi tersebut.

Kontrak yang harus dipertahankan:

**Hanya lokasi ini yang boleh dipindai**

**ALLOWED**

`Translation\en\Text`

**FORBIDDEN**

`Translation\en\Other`

`Translation\en\RedirectedResources`

`Translation\ja\Text`

Direktori `Text` yang tidak berada pada hierarki XUAT yang ditentukan.

File `.txt` di luar lokasi yang diizinkan.

Tambahkan negative tests untuk semua kasus tersebut.

**Temuan ketiga: Q-04 dan failing-first test harus dipisahkan.**

Q-04 adalah investigasi hasil pengujian manual.

Jangan memaksa `test_probe_4` gagal jika ternyata:

- Ikon `▶` memang merupakan Active Box marker yang benar.
- Masalah seleksi/drag tidak berhasil direproduksi.
- Ruby Preview harus dihentikan melalui STOP gate karena membutuhkan custom renderer.

Hanya bug yang benar-benar terkonfirmasi yang boleh mendapatkan failing-first defect test.
