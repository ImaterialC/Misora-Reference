CONFIRMED DEFECTS STILL IN CODE (priority order for a quota-limited Copilot)

P1-A REPLACE-ALL-BUNDLE-PREFILTER
File: misora.py multi-file Replace All (~8722–8735).
.unity3d/.asset candidates are counted with raw.read_bytes().count(utf-8 needle).
Structured text is only loaded later via load_bundle_story.
Impact: false hits (needle inside unrelated binary) and false misses
(text not stored as that exact UTF-8 byte sequence). User confirms a bad count,
then the real pass may change a different set of files.
Fix shape: prefilter by decoding dialogue via the existing bundle loader
(or skip count and scan boxes). Do not scan raw asset bytes for dialogue.
Scope: one function. No new subsystem.

P1-B REPLACE-ALL-UNDO-GAP
Same loop (~8762–8795). Plain-text files append (path, old, new) into
per_file_deltas and record BulkFileDelta. Bundle files call save_bundle_story
and increment replaced_files_count but are NOT journaled.
Impact: Undo after a mixed Replace All restores .txt only; bundles stay mutated.
Fix shape: journal a bundle delta (path + old serialized story or pre-save copy)
using the existing backup dir, then undo via the same restore path.
Do not invent a second undo stack.

P1-C BULK-DELTA-NONATOMIC
misora.py _apply_delta BulkFileDelta branch (~8914–8921) and the forward
replace path (~8783) use Path.write_text directly.
xunity_sync.py and bundle_io.py already use tmp + os.replace.
Impact: crash mid-write truncates a translation file. Undo of that bulk op
has the same hole.
Fix shape: one small helper write_atomic_utf8(path, text) and use it in both
places. Do not rewrite the journal.

P1-D SEARCH-RACE
on_start_search (~8028–8034) builds mem_docs[fp] = entry["doc"] and hands the
live StoryDocument to threading.Thread(_run_background_search).
AGENTS.md rule 15: workers must not touch live documents; pass immutable snapshots.
Impact: UI edit during search can change boxes the worker is reading
(torn text, rare exception, wrong hit offsets).
Fix shape: snapshot on the UI thread (v2 text or list of (uid, speaker, clean_text))
before Thread.start. Worker only reads the snapshot. Do not add locks around Tk.

P1-E FOLDER-DROP-EXTRA-IGNORED
_handle_dropped_paths (~2286–2287): if multiple directories are dropped,
only dirs[0] is passed to _process_opened_folder. Extra folders vanish with no status text.
Fix shape: if len(dirs) > 1, status/warning listing ignored folders OR open each
with the existing folder prompt. Prefer warn-and-open-first (smaller behavior change).

P2 CONFIRMED, DO NOT BLOCK A PATCH ON THESE
- OFFSCREEN-GEOMETRY: saved geometry is applied with bare self.geometry(saved)
  (~1253–1258) and no virtual-screen clamp. A missing monitor parks the window
  off-screen. Clamp to the primary screen before apply; ignore invalid strings.
- SPAN-NFKC-PER-CHAR: core/search_engine.py _norm_search_with_spans (~88)
  NFKC-normalizes each regex token, not the whole string. Japanese combining
  dakuten/handakuten that span a token boundary will not compose, so highlight
  spans can miss. story_ast.norm_search normalizes the whole string.
  Fix only if a fixture shows a miss; do not rewrite the search engine blindly.
- ICON-CACHE-GROWTH: low. Cache per Toplevel. Bound or drop on dialog destroy.
- THEME-RAW-PERF: measured note only (large RAM on big continuous view).
  Do not "optimize" without a new measurement.
- Plain-text reads in Replace All use errors="ignore" for counting and
  errors="replace" for rewrite (~8731, ~8776). A non-UTF-8 file can be
  silently altered. Prefer strict UTF-8 and skip+report on UnicodeDecodeError.
