### 2. Exact Canonical Text Projection & 8 Mandatory Data-Safety Invariants
- **Exact Projection Reference (`core/story_ast.py` — READ-ONLY):**
  * `Box.text` joins existing `Seg.text` values (`parts = [s.text for s in self.segs if s.text]; return "".join(parts)`).
  * `Box.clean_text` returns `game_to_xuat(self.text)`.
  * Quick Edit initial display MUST populate from **`box.clean_text`** — the exact same projection used by the main Dialogue Editor (`txt_dialogue`). NEVER write an independent segment-joining algorithm.
- **All 8 Mandatory Safety Invariants:**
  1. **Pre-First-Mutation Snapshot:** Capture complete `old_snapshot = BoxSnapshot.from_box(box)` (`seg_texts`, `raw_breaks`, `extra_args`, `speaker`, `voice_cue`, `kind`) bound to stable `box.uid` **strictly BEFORE the first live mutation** when a Quick Edit session begins (NEVER after edits begin or at session end).
  2. **Canonical Mutation Without `seg_texts`:** While editing, update live AST via `self.current_doc.inject_box(idx, None, new_tx)` WITHOUT passing `seg_texts` (exact same canonical text-distribution path as main Dialogue Editor).
  3. **Fresh Post-Edit Snapshot & Single Logical Undo:** On commit/flush, capture fresh `new_snapshot = BoxSnapshot.from_box(updated_box)` from the actually updated AST (ensuring updated `seg_texts` AND updated `raw_breaks` in `StoryDocument.records`) and record **EXACTLY ONE** `BoxSnapshotReplaceDelta` Undo transaction per edit session (never per keystroke).
  4. **Lossless Original-Segment Undo:** Undo (`StoryDocument.replace_box()`) MUST restore the EXACT original multi-segment split (`seg_texts`, `raw_breaks`, `extra_args`, `speaker`, `voice_cue`, `kind`) and underlying `StoryDocument.records`.
  5. **Exact Redo:** Redo MUST restore the exact edited state before Undo.
  6. **Binary Round-Trip Integrity:** `doc.to_binary()` -> `StoryDocument.from_binary()` MUST pass verbatim on edited, undone, and redone states, preserving `voice_cue`, `speaker`, `kind`, and command structure.
  7. **Immutable Keys & Lock UID Survival:** `_original_jp_by_uid`, `sync_manager.jp_source_cache`, `_modified_box_uids`, and `_locked_box_uids` MUST survive Edit, Undo, and Redo cleanly.
  8. **S09b Translation Lock Parity (Row 1) & Pin Independence:** Quick Edit MUST permit dialogue text typing on locked boxes identically to Manual Dialogue typing (no blanket disabled/read-only state), while leaving all operation-specific lock guards and Speaker Pin strictly orthogonal.
- **View-Aware Live Sync & Mandatory Flush Points (Preserved from S10):**
  * All Script mode: patch ONLY the active visible Virtualized Card in-place (`0` calls to `_render_continuous_view()` per keystroke).
  * Dialogue mode (Preview OFF): refresh `txt_dialogue` without feedback loop (`edit_modified(False)`).
  * Dialogue mode (Preview ON): refresh read-only `Dialogue Preview` capsule (no red overflow blocks per `Q-23`, `txt_dialogue_preview` stays `disabled`).

  * Mandatory flush before box navigation, view/mode switch, bottom-tab switch, raw-edit entry, doc switch, doc close, revert, save, Undo/Redo, and structural mutations.
