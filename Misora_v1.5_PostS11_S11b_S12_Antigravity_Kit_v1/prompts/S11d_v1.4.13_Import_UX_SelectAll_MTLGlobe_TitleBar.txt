### 1. `Q-06` (`U-22`) — MouseWheel Propagation in `ImportFromXUATDialog` (`misora.py`)
- Ensure `<MouseWheel>` scrolls the outer `ImportFromXUATDialog` canvas smoothly even when the mouse cursor hovers over ANY static info label, section header, status badge, frame, or checkbox (`Story Speaker`, `Story Metadata`, `Actor`, `No XUAT Match`, `Skip`, `XUAT Actor Match`, etc.).
- Preserve clean internal scrolling when intentionally interacting with focused multi-line text widgets (never hijacking intended inner scroll or causing double-scroll).

### 2. `Q-07` (`U-23`) — Per-Group Tri-State `Select All` in `ImportFromXUATDialog` (`misora.py`)
- Add a group-level `Select All` toggle control in the header of each of the 3 sections: **Metadata**, **Unique Actors**, and **Dialogue**.
- **Accurate None / Some / All (Tri-State) Handling:**
  * Track the exact state of eligible (matched, non-locked) rows in each group:
    - **All selected (0 skipped):** header displays checked state (`[✓]` / `Select All`).
    - **None selected (all skipped):** header displays unchecked state (`[ ]`).
    - **Some selected (partial):** header displays an explicit **indeterminate/partial visual state** (e.g., `[-]` / tristate indicator + accurate count `k/N`) — NEVER falsely displaying checked or unchecked when partially selected!
  * Clicking the group header toggles all eligible rows in that group cleanly (never unlocking or selecting locked dialogue rows) and updates summary counts immediately.

### 3. `Q-08` (`U-24`) — Multi-Line Synopsis (`summary`) in Metadata Import (`misora.py`, `core/xuat_cleanup.py`)
- Add a **Synopsis (`summary`)** row to Section 1 (Metadata) of `ImportFromXUATDialog` alongside Title and Subtitle (when Box 0 metadata has a synopsis / `summary` key):
  * **Multi-Line Wrapped Layout (REQUIRED):** Render paired read-only Synopsis boxes using **`wrap="word"`** and multi-line height (e.g., 4–6 lines, matching container width cleanly) — **NEVER force Synopsis into a 1-line `54d` box!**
  * Provide full **`◀ 1/N ▶` duplicate switcher**, provenance `filename:line`, and **`Skip`** checkbox (integrated into the Metadata group's `Q-07` tri-state `Select All`).
  * Include Synopsis in the Document Identity Guard (`_capture_doc_identity` / `_validate_document_identity`).
  * When unskipped and matched, apply via `doc.set_metadata(..., summary=new_summary)` and record inside the existing **`MetadataDelta`** in ONE atomic Import Undo batch (with full transactional rollback on mid-batch failure, and full Undo/Redo restoration).
  * When skipped or unmatched, existing Synopsis remains 100% untouched.
  * When applied and `var_archive_xuat` is checked, include the applied Synopsis entry as a non-speaker `AppliedXuatRecord` eligible for `XUAT Translation Archiving` (respecting pre-pass Actor exclusion).

### 4. `Q-09` (`U-25`) — Remove Leftover Archiving Sub-Header (`misora.py`)
- Audit all labels, headers, sub-headers, and status strings inside `XuatCleanupDialog` and its callers.
- Replace `"Import Complete - XUAT translation Archiving"` (and any remaining `"Import Complete"` cleanup header text) with clean, consistent **`"XUAT Translation Archiving"`**.

### 5. `Q-10` (`u-19`) — `Select All Box` Button & Checkbutton (`misora.py`)
- Add a **`Select All Box`** button and checkbutton control in the editor toolbar/selection area (clean text/checkbutton in `S11d`; `BoxSelectAll.png` icon will be wired in `S11e`).
- **Strict Selection Contract:**
  1. Selects/deselects **dialogue boxes ONLY** (`0 .. len(doc.boxes) - 1`).
  2. **MUST strictly exclude Box 0 (`-1`)**.
  3. **MUST NEVER mutate Translation Lock state** (`_locked_box_uids` / `_locked_boxes`).
  4. Works consistently in both `Dialogue` and `All Script` views, accurately reflects none/some/all selection state, and updates visible checkboxes and Paste Replace eligibility immediately.

### 6. `Q-11` (`u-3`) — MTL Globe (`🌐`) Official Website Button (`misora.py`)
- Add a compact Globe (`🌐`) button on each MTL engine card in the Right MTL Drawer.
- **Safe Default Contract (NO Unverified URL Prefill):**
  * Clicking `🌐` copies the active box's clean dialogue text (`box.clean_text`) to the system clipboard AND opens that engine's verified **official web translator homepage** via `webbrowser.open(...)`.
  * Emit a clear non-blocking status toast (`"Copied Box #N text to clipboard and opened <Provider> in browser"`).
  * Do **NOT** invent unverified URL query deep-links that claim prefill support.

### 7. `Q-12` (`u-16`) — Episode `Title (Subtitle)` in Window Title Bar (`misora.py`)
- Update the main window title formatter to display:
  `Misora: Story Editor - <filename>[*] — <Title> (<Subtitle>)`
  (omitting `(<Subtitle>)` if subtitle is empty, omitting `— ...` if both are empty).
- **Zero Disk Overhead:** Read exclusively from already-parsed `doc.get_metadata()` in memory (NEVER re-parse or touch disk).
