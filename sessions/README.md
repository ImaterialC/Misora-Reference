# Archived Debate Sessions

Optional folder for archiving completed multi-AI meeting artifacts so future AIs (or you) can reference past decisions without cluttering the repository root.

Recommended naming convention:
```text
sessions/
└── round-01-v1.4/
    ├── phase1_gpt.md
    ├── phase1_claude.md
    ├── phase1_gemini.md
    ├── manual_findings.md
    ├── phase2_5_canonical_ledger.md
    └── phase3_antigravity_prompts.md
```

> Note: Never treat old session archives as superseding the live source code in `Misora-Editor`. Always verify live files first.
