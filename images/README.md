# Supporting Visual References & Screenshots

Place UI mockups, game screenshots, bug screenshots, and layout references for multi-AI debate sessions here.

## Guidelines for AIs Inspecting `images/`
1. **Strict Scope Boundaries:** Treat screenshots strictly as visual references for the specific feature or bug the User describes. Do NOT extrapolate game screenshots into unrequested game replicas, emulators, asset extraction pipelines, or full application reskins.
2. **Phase 0 Visibility Check:** If you cannot visually view an image in this folder during Phase 0, declare it explicitly so the User can upload it directly to your chat or provide a text description.
