1. **Stabilization First:** Confirmed P0/P1 data-integrity, threading, and regression defects MUST pass before dependent UX/feature slices ship. `AGENTS.md` §24 MTL Drawer gate is relaxed strictly AFTER P0/P1 stabilization passes.

Bottom pane name LOCKED to **`Raw Commands`** (never `Raw Script` or `Raw File`). Keep internal Python identifiers (`var_continuous_view`, etc.) intact to avoid test churn.

Persisted lock key = `(box_ordinal, sha256(original_jp_text))`; runtime `Record.uid` is NEVER serialized. 6. **Speaker-Clear Box Separation (`QW-B01`, Lead Ruling (b)):** Clearing a speaker on a box adjacent to narration box(es) MUST keep them as separate boxes (insert minimum valid empty boundary breaker when post-edit projection would collapse adjacent boxes; NEVER implicitly merge).
7. **Multi-Segment Edit Policy (`Grok-B01`, Delegated Consensus):** Allow normal non-blocking editing in Dialogue/All Script views; show a small non-blocking `"N segs"` indicator; record `old_seg_texts` / `new_seg_texts` in `BoxEditDelta` (and propagate during undo coalescing) for lossless segment-level Undo; preserve full `BoxSnapshot` (`seg_texts`, `voice_cue`, `extra_args`) on internal Copy/Paste (`GEM-B09`).
8. **All Script MTL Drawer (`U-B33`):** LOCKED to exactly 2 Text widgets: (1) ONE read-only multi-line `tk.Text` list of clickable per-box tagged blocks + (2) ONE shared bottom editable `tk.Text` scratchpad, with 5 shared static theme-aware status tags (`✓`, `⏳`, `⚠`, `🔒` grayed via `fg_muted`, `-` grayed via `fg_muted`). Translation Lock MUST be enforced at the model/application layer, not only UI state.
9. **Import from XUAT (`U-B34`):** Strictly under the **Import** menu (separate floating window, NOT inside MTL Drawer; auto-closes MTL Drawer on open). Source strictly `BepInEx\Translation\en\Text`. Paired fixed `3 lines × 50 digit-widths` strictly **READ-ONLY** left/right boxes, NO visible per-box scrollbars, focus-gated inner scroll, duplicate `◀ 1/N ▶` + `filename:line`, per-box Skip + Lock auto-skip, explicit Pre-Apply confirmation listing exact imported / lock-skipped / user-skipped boxes, single atomic Undo batch.
10. **Windows `Ctrl+H` (`Grok-B06`):** Verified working by Project Lead on Windows v1.4.0 — CLOSED as a blocker (minor `bind_all` hygiene only in `HYG-07`).
