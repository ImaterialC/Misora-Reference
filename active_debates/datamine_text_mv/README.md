## Current phase rules

- Independent reviews first; do not expose one review to another model until the first pass is complete.
- Every claim must be labelled `CONFIRMED`, `UNVERIFIED`, or `CONTRADICTED` and backed by a path/code symbol or test result.
- No code changes, no Antigravity implementation prompt, no source cleanup, and no archive deletion in Phase 0.
- Consensus can be useful, but evidence and Product Owner approval determine the decision.
