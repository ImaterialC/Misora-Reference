Apa ini

Jangan tempelkan 23 sesi sekaligus. Jangan tempelkan README ini ke agent.

Urutan
1. Buka checkout Misora-Editor di Antigravity (App atau CLI agy). Mode plan atau default, bukan auto-push.
2. Pastikan HEAD awal adalah 683724edaf2afac89d2695a80e30a471a0da9195, atau pohon yang dihasilkan sesi sebelumnya.
3. Percakapan baru. Tempel seluruh isi prompts/S01.txt. Tunggu Implementation Plan. Baca. Baru klik Proceed.
4. Setelah Proceed, kalau agent berhenti terlalu awal, tempel cuplikan S01 dari AFTER_PROCEED_GOAL_SNIPPETS.txt.
5. Walkthrough harus memuat output asli. Kalau ada Probe yang sudah lulus sebelum patch, stop. Jangan lanjut sesi berikut.
6. Ulangi untuk S02, S03, dan seterusnya. Satu sesi selesai hijau sebelum sesi berikutnya.

Perintah yang dipakai, dan yang sengaja tidak dipakai
- Pakai /plan di awal setiap sesi. Ini wajib dari ANTIGRAVITY_GUIDE.md. Agent membaca disk, menulis rencana, berhenti.
- Pakai /goal hanya SETELAH Proceed, satu tujuan, dengan syarat selesai yang bisa diukur. Ada di file snippet.
- Jangan pakai /grill-me. Keputusan Phase 2.5 sudah dikunci. Interview akan membuka ulang debat.
- Jangan pakai /swarm atau /teamwork. Hampir semua sesi menyentuh misora.py. Worker paralel akan saling menimpa.
- Jangan pakai /boost pada tempelan awal. /boost langsung mengedit dan melewati gerbang rencana. Opsional hanya jika paket berbayar, hanya setelah Proceed, hanya untuk S10, S19, atau S22, dan hanya pada probe yang gagal.
- Jangan pakai /browser. Aplikasi ini Tkinter, bukan halaman web.
- Jangan pakai /run-workflow untuk menulis kode. Tidak ada fan-out file yang aman.
- /compact hanya sebagai token pertama pesan terpisah, kalau konteks sesi sudah panjang. Jangan disisipkan di tengah prompt.
- /btw boleh untuk pertanyaan sampingan read-only. Jangan untuk mengubah scope.
- /learn boleh setelah sesi jika agent mengulang kesalahan yang sama. Itu menulis rule, bukan fitur.
- Jangan /automation dan jangan /schedule. Eksekusi ini diawasi manual.
