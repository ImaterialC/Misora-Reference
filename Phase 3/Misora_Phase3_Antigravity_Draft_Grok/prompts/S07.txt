PART 2 — REQUIRED IMPLEMENTATION (BUG-13, BUG-15, BUG-16, BUG-17)
==================================================
### A. BUG-13 — mutate, then record undo, never swallow
Call inject_box first. Record the undo delta and mark dirty only if it succeeds.
Remove bare `except Exception: pass` on these paths. Log with logger.exception and set a status-bar error.
A failing inject_box leaves the undo stack and dirty flag unchanged.
### B. BUG-15 — non-contiguous cut restores exact indexes
BoxStructuralDelta stores the original index of each snapshot.
Undo puts each snapshot back at that index. Redo deletes those exact indexes.
Cut refuses or skips locked boxes.
Cutting indexes 1 and 4, then Undo, then Redo, restores the original order.
### C. BUG-16 — locks bind Clear Skeleton and Assistant Apply
is_box_locked() is enforced in both handlers, not only in the UI.
Clear Skeleton skips locked boxes and reports how many were preserved.
Assistant Apply blocks a locked box with a toast and reads the widget with get("1.0", "end-1c"). Do not .strip() the applied text.
Leading and trailing spaces and newlines survive.
### D. BUG-17 — coalesce only the same box uid
If both prev_delta.box_uid and delta.box_uid are not None, coalesce only when they are equal.
Fall back to box_index only when at least one uid is None.
When coalescing a BoxEditDelta, update new_seg_texts as well as new_text (the fields S05 added).
Two different non-None uids at the same index must not coalesce.
