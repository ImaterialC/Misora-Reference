### A. FEAT-14 — separate importer, one index, explicit apply
Add Import > Import from XUAT. It is a separate window, not a drawer tab.
Opening it closes the MTL drawer.
Read only BepInEx\Translation\en\Text under the current project. Refuse any other root.
Build one in-memory index in core/xuat_index.py with a single background pass, sharing the existing var_xuat_cache behavior if that cache already exists. The worker must not touch Tk. Results arrive on a queue.
Do not port these traps: splitting on an unescaped equals sign, a block-mode hijack, unconditional global conflict resolution, a non-deterministic fuzzy slice, a normalizer that drops NGUI tags or treats {playername} and {0} as unrelated, global pruning, speaker-blind completion, or a find_match 3-tuple mismatch. No conflict_manager.
UI: one outer scrollable list of pairs. Each side is a read-only box fixed at 3 lines by 50 digit-widths. No per-box scrollbar.
Mouse wheel scrolls the outer list. A focused box may scroll its own overflow with the wheel, and Shift+wheel or drag. Show a small overflow marker.
Duplicates show a prev/next control with "1/N" and filename:line.
Conflict scope is three tiers: This Box (default), This Story, Global opt-in.
Each row has Skip. Locked boxes are skipped and grayed automatically.
Filter chips: All, Duplicates, Missing, Matched.
Optional speaker-translation checkbox with separate dialogue and speaker counts.
A literal backslash followed by n in the XUAT file becomes a real newline on display and on apply. Do not destroy other backslash sequences (S03 parity).
Pre-Apply confirmation lists: boxes to import, lock-skipped boxes, user-skipped boxes, and the missing count. No means no writes.
Apply is one undo batch with source xuat_import.
