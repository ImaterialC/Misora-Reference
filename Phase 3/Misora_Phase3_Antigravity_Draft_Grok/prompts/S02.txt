PART 2 — REQUIRED IMPLEMENTATION (BUG-33, BUG-32, BUG-36, BUG-35)
==================================================
### A. BUG-33 — DPAPI fail closed, decrypt must warn
On Windows DPAPI encryption failure: raise an explicit security error and surface a UI warning. NEVER silently write a plaintext key into misora_config.json.
Keep legacy plaintext READ compatibility.
On decryption failure: do not return "" and do not wipe the stored ciphertext. Surface an explicit warning and preserve the stored value.
Tests must mock DPAPI. Do not call real Windows crypto and do not write a real key.
### B. BUG-32 — logger flush barrier and teardown
MisoraLogger.flush must wait for in-flight disk writes using task_done or an equivalent completion barrier with a bounded timeout. Do not treat queue.empty() as proof that writes finished.
On app teardown, call logger.close() and cancel pending Tk after jobs via tk.call("after", "info").
clear_log_file must leave zero stale trailing writes.
### C. BUG-36 — splash sort must tolerate non-numeric names
Sorting Splash_*.jpg must not raise ValueError on a suffix that is not an integer (example: Splash_custom.jpg). Use a regex or a fallback tuple. Do not change the order of the existing numeric Splash_1..Splash_N files.
### D. BUG-35 — defer startup session restore
Do not load initial_path or _saved_opened_files synchronously before the window maps.
Schedule that restore with after_idle, and only after self.deiconify(), per AGENTS.md startup rules.
The window must be mapped before those files are opened.
