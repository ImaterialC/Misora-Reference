==================================================
### A. BUG-11 — save the plain-text buffer, never the preview widget
Plain-text on_save writes self._plain_text_content.
It must not read compiled, tag-stripped text from txt_dialogue or txt_continuous while Preview is ON.
Flush the widget into _plain_text_content only when Preview is OFF.
Saving a .txt that contains NGUI tags while Preview is ON must preserve those tags byte for byte.
This is a hard gate for later preview and XUAT import sessions.
### B. BUG-18 — always write pre-encoded bytes
Remove the tmp_file.write_text(content) fast path in write_atomic_encoded.
Always write the already encoded bytes with tmp_file.write_bytes.
LF-only input must stay LF on Windows (zero CR LF pairs).
on_export_script must call write_atomic_encoded(..., newline="\n").
### C. BUG-19 — zero-box story saves
Guard the preview, continuous, and page branches of on_save when the story has no boxes.
A metadata-only story must save in all three modes without IndexError.
### D. BUG-20 — backup names cannot collide
Every backup written by on_save and by on_replace_all (text and bundle) uses a microsecond timestamp plus a short deterministic hash of the normalized full source path, or a mirrored relative directory.
If that path already exists, refuse or disambiguate before writing.
Two files with the same stem in different folders, saved in the same second, must produce two different backup paths.
