# Reference Library

This folder is for reference materials that help understand the existing toolchains and desired UI/data behavior.

- `assets/` contains owner-supplied screenshots/diagrams. Preserve originals and descriptive filenames until they have been indexed.
- The owner-supplied `Misora-Reference.rar` is initially kept at the repository root. Its contents must be inventoried and verified during Phase 0 before any extraction results are reorganized.
- Extracted source code should first go into a dated, read-only staging area such as `references/extracted/2026-11-23/`. Keep the original directory hierarchy.
- Do not place runtime databases, live game bundles, decrypted assets, personal translation dictionaries, or secrets in this public reference repository.

Create `references/SOURCE_CATALOG.md` only after the archive has been inspected. For every tool, record original path, program name, purpose, entry points, dependencies, data formats, tests, version/history clues, license, SHA-256, duplicate relationships, and whether it is a candidate for reuse.
