## 3. Preliminary Audit Findings (Hypotheses for Cross-Check & Debate)

### A. Potential Bugs & Edge Cases to Verify
1. Monolithic `misora.py` (~510 KB) Coupling: A very large main module increases the risk of tight UI-to-core coupling, state desynchronization between `story_ast.py` / `undo_journal.py` / UI widgets, and regressions when modifying one flow.
2. Undo/Redo vs. External Sync (`undo_journal.py`, `xunity_sync.py`, `bundle_io.py`): Undoing or redoing edits may not cleanly revert or re-sync external XUnity / bundle state, or may leave stale caches/AST references.
3. Tag & Codec Round-Trip Fidelity (`ngui_tags.py`, `script_codec.py`, `story_ast.py`): Nested/malformed NGUI tags, escape sequences, or non-standard line endings/encodings during import -> AST -> edit -> export round-trips risk silent text corruption or dropped tags.
4. Path Traversal & File Association Safety (`security.py`, `bundle_io.py`, `*.bat`): User-supplied paths, bundle extraction/writing, or Windows file-association batch scripts (`register_association.bat` / `unregister_association.bat`) should be audited for path validation, quote handling, and failure recovery.
5. Test Coverage vs. Reality Gap (`tests/`): Passing unit/phase tests can mask brittle UI integration (`test_misora_ui_integration.py`) or untested edge cases in real `.unity3d` bundles (`1001005.unity3d`, `storydata_1001005.unity3d`).

### B. Performance & Efficiency Optimizations to Evaluate
1. Large Story / Bundle Loading & Search (`story_ast.py`, `search_engine.py`, `bundle_io.py`): Repeated full scans, unindexed regex/string searches, or redundant AST rebuilds on large story datasets can cause UI freezes.
2. Logger & Journal Overhead (`logger.py`, `undo_journal.py`): Frequent fine-grained logging or deep-copying large AST/state snapshots on every action can bloat memory and slow down bulk edits.
3. Startup & Asset / Config Loading (`misora.py`, `misora_config.json`, `assets/splash.py`): Deferring heavy initialization until needed and validating config defaults cleanly can improve startup responsiveness.

### C. Practical Feature & Workflow Ideas (Scoped for Indie/Copilot Execution)
1. Round-Trip Integrity Check / Dry-Run Diff: A pre-export or pre-sync check that highlights modified lines, broken tags, or untranslated/unmapped entries before writing bundles or XUnity files.
2. Search & Filter Ergonomics: Scoped search (e.g., filtering by speaker/node/tag/untranslated state) with safer bulk replace preview in `search_engine.py`.
3. Resilient State Recovery: Safer autosave/backup recovery independent of `PROJECT_STATE.md` so work is protected even if session/state files change or are removed.
4. Lean Developer & Copilot Guardrails: Clear, modular boundaries and focused test targets so Copilot can make small, verifiable changes without touching unrelated 510 KB sections of `misora.py`.
