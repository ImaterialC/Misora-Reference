PART 3 — BRAND-NEW UNMENTIONED BUGS, TRAPS & ANTI-OVERENGINEERING TRIMS
======================================================================

1. [NEW TRAP — HIGH] `box_uid` LIFECYCLE ON RELOAD & CLOSE:
   - `box.uid` / `Record.uid` is generated via in-memory `itertools.count(1)`.
   - On `reload_from_disk=True` (or close + reopen), every box receives brand-new UIDs!
   - Risk: Once locks (`N-D`), JP keys (`F7`), and async targets (`F10`, `NEW-3`) use `box.uid`, stale UIDs left in `sync_manager` or lock sets will leak memory across a long session and silently break locks/JP lookup after a reload.
   - Rule for RUN 2/3: Scope or clear/re-register UID-keyed registries on `reload_from_disk` and prune them on `close_file`.

2. [NEW SECURITY/HYGIENE RISK] TRACKED `misora_config.json` IN PUBLIC REPO:
   - `misora_config.json` (2,286 B) is currently tracked in the repo. Writing user prefs, local paths (`D:\...`), recent files, or MTL settings directly to a tracked file risks accidental public git commits or `git pull` clobbering user settings.
   - Verify what `misora_config.json` holds today; consider keeping a tracked `misora_config.example.json` and ignoring runtime user config (or storing user prefs outside tracked files).

3. [NEW WINDOWS BUG — NEEDS-VERIFY] FILE ASSOCIATION `cwd` & QUOTING (`*.bat`):
   - Repo ships `misora.bat`, `register_association.bat`, `unregister_association.bat`.
   - When Windows Explorer opens a `.unity3d` file via file association, `cwd` is often NOT `D:\Misora-Editor`, and paths may contain spaces or Japanese characters.
   - Audit whether config/assets/backup lookups resolve relative to `Path(__file__).resolve().parent` (safe) vs `Path.cwd()` (breaks on double-click launch!), and verify `"%*"` quoting in `misora.bat`.

4. [NEW PERF TRAP] IN-APP CONSOLE (OPTION A) UNBOUNDED TEXT GROWTH:
   - An in-app `tk.Text` console fed by async `core/logger.py` during a 300k-line XUAT scan or bulk search will freeze Tk if unbounded.
   - Mandatory guardrails when building Console (Option A):
     * Ring-buffer line cap (e.g., max 2,500 lines; trim oldest lines on insert).
     * Drain in bounded batches (e.g., <=100 lines per existing 100ms UI poll tick — no extra timer).
     * Smart auto-scroll: follow bottom ONLY when scrollbar is already near bottom (`yview()[1] >= 0.98`).

5. [NEW MEMORY GUARD] `BulkFileDelta` BUNDLE UNDO RAM CAP:
   - Journaling multi-file Replace All for 50–200 `.unity3d` bundles (`F5`) must NOT hoard raw bundle bytes or huge v2 strings in RAM indefinitely.
   - Store pre-replace bundle backups in a managed temp/backup dir referenced by path in the delta (or cap bulk undo entries), ensuring atomic restore on Undo and cleanup on exit/prune.

6. [ANTI-OVERENGINEERING TRIMS]:
   - Drop premature lazy-loading placeholders `{doc: None, loaded: False}` in RUN 3b -> use batched multi-select with single final UI render/list refresh (GPT Round 2 §7).
   - Drop disk sidecar index cache in XUAT v1 -> start with background in-memory scan and measure first (GPT Round 2 §6).
   - Trim low-ROI churn from Qwen Round 3 (`NEW-19` getter refactor, `NEW-24` background-close refactor unless directly needed by F2/F3, `NEW-22` CLI multi-arg optional).

7. [LEAN PRICONNE FANSUB QA INNOVATIONS — LOW LOC, HIGH VALUE]:
   - **Placeholder `{0}` Parity + Unclosed NGUI Tag Check (<20 LOC):** Flag if original JP has `{0}` (or NGUI color/style open tag) and EN drops `{0}` or leaves tags unbalanced. Fits neatly into Editor status bar + MTL Drawer + Import from XUAT.
   - **3-Line In-Game Overflow Indicator (`Lines: X/3`):** Companion to existing char-count badge so translators catch Priconne 3-line clipping early.
