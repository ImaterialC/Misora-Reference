NEW OR SHARPENED (not a new epic)

N-G  MTL-TEXT-IS-A-FAKE-EDITOR
_get_active_text_widget() returns whatever tk.Text has focus (misora.py ~5716–5718).
Ribbon insert, size tags, and several commits follow that widget.
An editable MTL scratchpad is a tk.Text. If it is focused, those commands can treat the translation scratchpad as the story box, or the reverse.
Ctrl+Z isolation alone is not enough.
Fix: mark the scratchpad (a flag or widget class) and exclude it from _get_active_text_widget, MisoraShortcuts document bindings, and save-from-widget. Local undo=True stays inside the scratchpad only. Ctrl+Enter = Apply. Ctrl+S must still save the story, not the scratchpad.

N-H  OPEN-TEXT-LOSSY-DECODE
open_file() reads non-bundles with encoding="utf-8", errors="replace" (misora.py ~6138).
A bad byte becomes U+FFFD and the load is reported as success. The next save writes the damage.
Replace-All's lossy decode is already F5. This is the open path, and it is not in that slug.
Fix: strict UTF-8. On UnicodeDecodeError, show the error and leave the previous document untouched (same commit rule as F1). Do not offer "replace and continue" in v1.

N-I  F1 IS WORSE THAN "PATH/DOC MISMATCH"
Before load_bundle_story / from_v2_text, open_file already does (misora.py ~6102–6108):
  current_file_path = new path
  is_dirty = False
  _modified_boxes.clear()
  _original_box_texts.clear()
  _locked_boxes.clear()
and the window title + recent_files are updated even earlier (~6073–6080).
On exception the old StoryDocument object is left in place, but its lock set, dirty flag, and JP baseline are already gone, and the title names the file that failed.
Fix stays the Round 2 one: stage locals, commit self.* only after success. Also do not touch title, recent list, locks, or dirty flags until commit.

N-J  SWITCH-SKIPS-FLUSH  (CONDITIONAL)
open_file() never calls _commit_widget_edit() before swapping documents.
KeyRelease usually commits typing. An IME composition, a programmatic insert, or a focus change that never generated KeyRelease can be dropped on file switch.
AGENTS rule 13 already requires a flush before navigation. One call at the top of open_file. No new session manager.

NOT NEW — DO NOT REFILE
- Cache switch leaks _locked_boxes and rebuilds JP keys from current English text. Round 2 already has this (~line 269). Same fix as uid identity.
- Console is a dead control. Confirmed: F12 only toasts "Logs stream to the persistent Windows console" (~5710–5712). txt_console is never built. Preference: option B for the next slice (stop pretending an in-app console exists). Option A is a feature, not a bugfix. Ask the user once; do not build it inside RUN 1.
- Left dock default is "search"; the button says "Opened Files"; askopenfilename is single-file (~1118, ~3254, ~8377). Qwen C-V1/C-V2 match the code.
- Splash cannot paint before Tk exists. Measure first. Do not add a second process.

LAZY OPEN — CONSTRAINT, NOT A NEW DESIGN
_add_project_paths() may register paths before parse, but these callers assume a real doc or real text today:
  search mem_docs = entry["doc"]
  close_file dirty flag
  Replace All reload of the active path
A placeholder {loaded: False, doc: None} without a load-on-demand guard will make "current file" search skip the story or throw.
Rule: inactive paths may stay unloaded; the active path and any search/replace/save target must load first. One summary toast for failures. Do not parse 50 bundles just to list them. Do not draw Continuous View more than once.
