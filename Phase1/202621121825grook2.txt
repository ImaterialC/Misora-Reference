N-A  AFTER-SWEEP-REGRESSION  (ledger is wrong)
PROJECT_STATE claims MisoraApp.destroy() sweeps `after info` plus toast/resize/eyedropper.
Actual destroy() (misora.py ~1375) cancels only _search_poll_job, then super().destroy().
Toast and continuous-resize jobs are cancelled only on their own success paths.
Impact: headless tests can still hit "invalid command name" on teardown.
Fix: one cancel-all in destroy(), matching the ledger. Do not invent a new lifecycle class.

N-B  CLOSE-FILE-IGNORES-SAVE-FAILURE
close_file() asks Save, calls on_save(), then ALWAYS deletes the doc (misora.py ~9033–9046).
It never re-checks is_dirty. A failed save still drops the in-memory document.
_on_app_exit() is stricter for the ACTIVE file only (returns if is_dirty stays true).
Fix: if the user chose Save and the file is still dirty, abort the close.

N-C  EXIT-MULTIDOC-SAVE-GAP
_on_app_exit() prompts when ANY open doc is dirty, then calls on_save() once.
on_save() writes only current_file_path. Other dirty docs are destroyed.
Fix: loop dirty paths, switch or save each, abort exit if any save fails.
If this is already your N9, keep one slug. Do not file a second feature.

N-D  LOCK-INDEX-DRIFT  (distinct from JP-key uid work)
_locked_boxes is Set[int]. Nothing remaps it on insert/delete/move.
Paste-box or delete shifts later locks onto the wrong boxes.
Locks are also cleared on every file open (~6107), so they are session-index state.
Single-box MTL _on_apply() never calls is_box_locked(). Batch translate does.
A drawer "Apply" that copies _on_apply() will ignore Translation Lock.
Fix now, small: key locks by box uid; check the lock in every apply path
(batch, script paste, replace-all, MTL apply). Do not wait for XUAT import.

N-E  SAVE-TEXT-NONATOMIC  (not the same as bulk replace)
Bundle save uses tmp + os.replace. Plain-text save and v2 save use
Path.write_text directly (misora.py ~7870 and ~7919). Crash mid-save truncates
the user's script. Same helper as the bulk-replace fix. One helper, three call sites.

N-F  COMPARE-ALL-UNBOUNDED
Translator "_on_fetch_all" always spawns Google + DeepL + Sugoi + LLM + XUAT
with no confirm, no shared cache, no cancel token (misora.py ~10890).
