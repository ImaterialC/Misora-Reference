### A. Speaker Cyclic Jump (`▼`) vs Google-Style Autocomplete Rename (`U-3`, `U-4`)
1. **Repurpose `btn_speaker_dropdown` (`▼`) -> Jump to Speaker Box (`U-3`):**
   - Clicking `▼` shows a popup menu listing all unique speakers in `self.current_doc` (plus `(Narration)` if narration boxes exist) with occurrence counts (e.g., `Hiyori (12)`).
   - Selecting a speaker **navigates** to that speaker's box (does NOT rename the active box):
     - First selection jumps to the speaker's first occurrence (or first occurrence after `current_box_idx` if already viewing that speaker).
     - Clicking the same speaker again cycles to the **next** box spoken by that character, wrapping around to the first occurrence when reaching the end.
   - Always emit a clear status bar + toast notification: e.g., `Jumped to Box #24 — Hiyori (3/12)`.
   - Update `btn_speaker_dropdown` tooltip to `'Jump to Speaker Box (click again to cycle next)'`.

2. **Google-Style Autocomplete Popup on `entry_speaker` (`U-3`, `U-4`):**
   - Renaming a speaker happens by typing in `self.entry_speaker` (disabled when `is_box0_active`).
   - Implement a lightweight autocomplete popup (`tk.Toplevel` with `overrideredirect(True)` + `tk.Listbox`, parented to `self`, strictly guarded with `winfo_exists()`, destroyed cleanly on Escape / FocusOut / root destroy):
     - Opens automatically when the user clicks/focuses `entry_speaker` or deletes the text down to empty.
     - Lists `sorted(current_doc.actors())` + `{playername}` + `(Narration — Clear Speaker)` and filters live as the user types.
     - Supports `Down`/`Up` arrow selection, `Enter` or mouse click to pick an item, and `Escape` to dismiss without changing.

3. **Speaker Commit Safety & Notification Hygiene (`U-4`):**
   - **STOP committing on every `<KeyRelease>`** (previously backspacing character-by-character triggered transient narration conversion & undo spam). Commit rename ONLY on `Enter`, autocomplete selection, or `FocusOut` (and on `_flush_active_widget()` before save/tab switch).
   - **Enforce Translation Lock in `_commit_speaker_edit()`:** If `self.is_box_locked(idx)` is True, refuse the rename, revert `speaker_var` back to `box.speaker`, and show a clear toast (`Box #N is locked; speaker rename blocked.`).
   - Preserve adjacent-narration separation invariant (`QW-B01`) when clearing a speaker to `''`.
   - Emit distinct, accurate notifications for Rename (`Renamed Box #N speaker -> <Name>`) vs Jump (`Jumped to Box #N — <Name> (k/M)`).
