### A. Fix Leaked 3rd Window Above Raw Commands & Redundant Rebuilds (`U08`)
- **Confirmed Bug:** `_update_empty_state_visibility()` packs `self.gd_scroll_wrap` whenever `has_docs` is True **without checking `self.var_continuous_view.get()`**, causing Dialogue View to leak directly below All Script (above Raw Commands).
  - Fix: only pack `gd_scroll_wrap` when `has_docs and not (getattr(self, "var_continuous_view", None) and self.var_continuous_view.get())`.
- **Eliminate Redundant Rebuilds:**
  - In `on_box_new()` and `_on_card_paste_caret()`, call `_render_continuous_view()` ONLY when `self.var_continuous_view.get()` is True.
  - In `on_box_paste()` and `on_box_cut()`, avoid duplicate `_update_raw_view()` / `_render_continuous_view()` invocations.

### B. All Script Performance Overhaul — Technique A (`U08`, `U-7`)
- Replace the heavy multi-widget card loop in `_render_continuous_view()` (which previously destroyed and recreated 10–15 Tk widgets per box = 1,500+ widgets on 150-box stories) with **Technique A**:
  - Render all story boxes (including Box 0 metadata when present) inside **ONE read-only `tk.Text` widget** (e.g., `self.txt_all_script`, keeping `self.txt_continuous` intact as plain-text fallback without mis-aliasing).
  - Use cached clean-room Pillow header/divider images inserted via `image_create()` + `lmargin`/`rmargin`/background tags so scrolling is **100% natively synchronized** with zero multi-widget creation lag.
  - Maintain a deterministic block map (`self._all_script_block_ranges` / mark spans) mapping line ranges to `box_idx` (`-1` for Box 0, `0..N-1` for dialogue boxes).
  - **Interactions in Technique A All Script:**
    - Single click on any box block: selects that box (`current_box_idx` / `is_box0_active`), highlights active box block in-place (NO full re-render!), syncs Speaker bar, Box counter, Raw Commands, and MTL Drawer.
    - Double-click or `Enter` on any box block: switches cleanly into Dialogue View focused on that exact box for editing.
    - Clickable inline Select Box checkbox tag (when `Select Box` mode is ON) toggles `self._selected_boxes` in-place; clickable inline Lock badge toggles Translation Lock in-place.
    - Measure and record before/after render time for a 150-box synthetic story in the Walkthrough artifact.
  - Update affected S13/S15 continuous-view tests cleanly per Amendment `AMD-03` (without weakening lock, selection, or dirty-state invariants).
