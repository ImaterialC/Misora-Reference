### A. Pure-Python NGUI-Aware Auto Word Wrap Engine (`core/word_wrap.py`, `U07`)
**Context:** XUnity.AutoTranslator relies on runtime plugin word-wrap, so XUAT `.txt` translations are typically single unwrapped lines. Once imported into `.unity3d` story bundles (rendered natively without plugin wrap), lines overflow the game's `50d x 3` box.

Create `core/word_wrap.py` (ZERO Tkinter imports — accepts a `measure_fn: Callable[[str], int]` and `safe_width: int` calibrated to constant `50d` `Nunito Bold`):
1. **Atomic Tokenization:**
   - Tokenize text preserving NGUI tags (`[b]`, `[/b]`, `[RRGGBB]`, `[-]`, `[rub:ruby]base[/rub]`, `<size=...>`, etc.) and placeholders (`{playername}`, `{0}`) as indivisible atomic units (tags measure `0px`; ruby measures its `base` text width; `{playername}`/`{N}` measures `'PlayerName'` proxy width — matching `_measure_dialogue_metrics()`).
   - **Malformed tags** (e.g., unclosed `[FF0000` or stray `[rub:foo`) MUST be treated safely as literal text without crashing or stripping characters.
   - NEVER inject CSIF headers (`@@...`) or empty binary arguments.
2. **Wrapping Rules (EN & JP Aware):**
   - Preserve existing intentional `\n` paragraphs by default (`reflow_existing_breaks: bool = False`, wrapping only lines exceeding `safe_width` so manual breaks stay intact; optional `reflow_existing_breaks=True` to re-flow full paragraphs).
   - For Latin/English text: break cleanly at word/whitespace boundaries; collapse the split space cleanly at line break; only hard-break an overlong single token if it alone exceeds `safe_width`.
   - For CJK/Japanese text (no spaces): break at character boundaries while applying basic kinsoku protection (avoid starting a new line with closing punctuation `。、！？）」』…・` or ending a line with opening brackets `（「『`).
   - Return a structured `WrapResult(wrapped_text, original_lines, new_lines, still_overflows_lines: bool, still_overflows_width: bool, changed: bool)` so callers can report boxes that still exceed 3 lines (meaning-preserving — NEVER truncate or rewrite words to force 3 lines!).

  - Option: `Preserve existing line breaks (wrap long lines only)` (default ON) vs `Reflow all paragraphs`.
