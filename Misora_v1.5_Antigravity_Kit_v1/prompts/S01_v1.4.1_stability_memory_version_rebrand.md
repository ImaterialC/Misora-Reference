### A. Stability & Memory Remediation (Highest Priority — P1/P2)
1. **`BUG-01` — Per-Job Search Cancellation & Clean Shutdown (`misora.py`, `core/search_engine.py`):**
   - Replace the shared mutable boolean `self.search_cancel_flag` race with a per-job `threading.Event` (e.g., `self._search_cancel_event`) captured by the worker closure so starting a new search NEVER un-cancels an older worker.
   - Keep `self.search_cancel_flag` as a synchronized backward-compatible attribute/property if existing tests read it, while the worker checks `job_cancel_event.is_set()`.
   - Bound `self.search_queue` (e.g., `maxsize=2048`) or put with bounded drop/cancel check so a stalled UI never grows memory unboundedly.
   - In `core/search_engine.py:search_directory()`, check `if should_cancel and should_cancel(): break` **inside the `os.walk()` loop** as well as the per-file scan loop.
   - Signal cancellation of any active search worker in `MisoraApp._on_root_destroy()` and `MisoraApp.destroy()`.

2. **`BUG-02` & `BONUS-02` — Bounded MTL Worker Pool + Shared SSL Context (`misora.py`, `core/mtl_engine.py`):**
   - In `core/mtl_engine.py`, cache ONE thread-safe module-level SSL context via `_get_shared_ssl_context()` instead of calling `ssl.create_default_context()` inside every `MTLEngine.__init__()` (which reloads the Windows OS root cert store per box).
   - Add a bounded `concurrent.futures.ThreadPoolExecutor` (e.g., `max_workers=3`, named `MisoraMTLWorker`) or bounded worker queue for `All Script` `Translate All` (`_on_mtl_all_script_translate_all()` / `_dispatch_mtl_all_box()`) with a per-batch/app `threading.Event` cancel token and honoring `self.mtl_config.rate_limit_delay` between network requests. Do NOT spawn 1 OS thread per box (e.g., 500 boxes MUST NOT spawn 500 threads).
   - Cancel pending MTL All Script work cleanly on document close, engine switch, and `MisoraApp.destroy()`.
   - Keep `translate_async()` signature 100% backward compatible for existing callers and tests.

3. **`BUG-03` & `BONUS-01` — Document-Scoped Cache Pruning on Close & Reload (`misora.py`, `core/xunity_sync.py`):**
   - Add a helper `_prune_document_caches(self, file_path: Optional[Path], doc: Optional[Any])` invoked in `close_file()`, `_close_all_documents_without_prompt()`, and `open_file(..., reload_from_disk=True)` (before replacing prior entry).
   - Prune ALL entries belonging to the closed/reloaded document from:
     - `self._mtl_all_results`, `self._mtl_all_statuses`, `self._mtl_all_errors` (match by `file_path`, `doc_id`, or `box_uid`),
     - `self._mtl_all_req_seqs` & `self._latest_applied_mtl_seq` (match by document's box UIDs),
     - `self.sync_manager.jp_source_cache` (add `unregister_jp_keys(uids)` helper on `XUnitySyncManager` and call it for the closed/reloaded document's box UIDs).

4. **`BUG-04` — Dispose UnityPy `env` on Error Paths (`core/bundle_io.py`):**
   - In `load_bundle_story()`, once `env = get_unitypy().load(raw_bundle_bytes)` succeeds, wrap the TextAsset discovery, extraction, and `StoryDocument.from_binary()` in `try ... except Exception: dispose_unity_env(env); raise` so no UnityPy environment leaks on failed/corrupt loads.

5. **`BUG-05` — Deterministic `MisoraLogger.close()` Shutdown (`core/logger.py`):**
   - Add `self._stop_event = threading.Event()` to `MisoraLogger`.
   - In `_file_writer_loop()`, read from `self._file_queue.get(timeout=0.1)` so the thread wakes periodically and exits cleanly when `self._stop_event.is_set()` and the queue is drained (or sentinel `None` is received).
   - In `close()`, call `self.flush(timeout=1.0)`, set `self._stop_event.set()`, try best-effort `put_nowait(None)` without failing on `queue.Full`, call `join(timeout=1.0)`, and only clear `self._writer_thread = None` once the thread is no longer alive. Reset `_stop_event` if writer thread is intentionally restarted.

6. **`BUG-06` — Atomic `_is_saving` Guard Placement (`core/bundle_io.py`):**
   - In `save_bundle_story()`, initialize `tmp_path: Optional[Path] = None` BEFORE `try:`, then move `out_path = Path(out_path)`, `out_path.parent.mkdir(parents=True, exist_ok=True)`, and `tmp_path = ...` **INSIDE `try:`**, guarding `if tmp_path is not None and tmp_path.exists():` in `finally:` so `_is_saving = False` is GUARANTEED even if `mkdir` raises `PermissionError` or `OSError`.

7. **`BONUS-03` — Stop Idle Polling & Eliminate Double Reload (`misora.py`):**
   - Run `_poll_mtl_queue()` and `_process_search_queue()` ONLY while work is actually in flight (schedule via `after()` when a search or MTL box request starts; stop rescheduling once idle/finished), mirroring `_poll_mtl_drawer_queue()`.
   - In `_apply_delta()` for `BulkFileDelta`, avoid calling `self.open_file(self.current_file_path, reload_from_disk=True)` when the active bundle/text cache was ALREADY refreshed in the loop above — refresh UI via `_update_views()` and `_dirty_state_changed()` directly instead of loading the bundle twice from disk.
