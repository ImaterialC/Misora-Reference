### 1. `U-01` — Native Paste Box Selection Model (`misora.py::on_box_paste` & paste chooser)
- **Replace Mode (Strict Selection Contract):**
  1. Target indices MUST be sourced exclusively from `sorted(self._selected_boxes)` (works identically in both `Dialogue` and `All Script` views).
  2. **Empty Selection (`len(_selected_boxes) == 0`):** Nothing may be replaced. In the 3-way Paste chooser dialog, disable (gray out) the `Replace` button and show an explicit inline hint (e.g., `"Select target box(es) first to Replace"`). If Replace is invoked directly/programmatically with empty selection, abort before mutation and show a clear notification (`"No boxes selected to replace."`).
  3. **Box 0 Rejection:** Box 0 metadata (`-1`) MUST NEVER be treated as `doc.boxes[-1]`. Reject `-1` explicitly from Box Replace with a clear notification before mutation.
  4. **Exact 1:1 Count Equality:** Require `len(selected_targets) == len(clipboard_snapshots)`. If counts differ, abort before mutation and display BOTH counts (e.g., `"Selected 3 boxes, but clipboard contains 2 boxes."`). Never silently clamp, partially replace, or append extra content.
  5. **Locked Targets:** Validate ALL target boxes against `self.is_box_locked(idx)` BEFORE mutating anything. If ANY target is locked, abort atomically and report the locked box(es) — NEVER silently skip a locked box or shift subsequent clipboard items onto the wrong box.
  6. Apply all validated replacements in ONE atomic Undo batch (`BoxSnapshot` lossless preservation of `speaker`, `voice_cue`, `kind`, `seg_texts`, `raw_breaks`, `extra_args`) and ensure full Undo/Redo restoration.
- **Insert Mode:**
  1. `_selected_boxes` is used exclusively by Replace; Insert uses the active box as its insertion anchor.
  2. **Box 0 Active Rule:** When Box 0 is active (`self.is_box0_active` is `True`), Insert MUST insert the clipboard box(es) **before the first dialogue Box** (insertion index `0`), preserving full Undo/Redo restoration.

### 2. `U-02` — Pin Speaker (`📌`) Navigation & Captured Identity (`misora.py`)
- Maintain a dedicated captured identity attribute (e.g., `self._pinned_speaker_name: Optional[str] = None`) when Pin (`📌`) is toggled ON, capturing the active box's current speaker (including empty string `""` for Narration). NEVER re-read `self.speaker_var.get()` as the navigation target on `Next`/`Prev` after a speaker rename!
- **Navigation Boundary Contract:** Navigation boundaries are explicitly the **current loaded `StoryDocument`** (`0 .. len(doc.boxes) - 1`). **NO wrap-around** (cyclic jump remains exclusively on the `▼` speaker dropdown menu).
  - When Pin is active and user invokes `Next`: find the next box index `> current_box_idx` with `box.speaker == self._pinned_speaker_name`. If none exists, stay on the current box and emit status/toast containing `"the last time speaking in this chapter"`.
  - When Pin is active and user invokes `Prev`: find the previous box index `< current_box_idx` with `box.speaker == self._pinned_speaker_name`. If none exists, stay on the current box and emit status/toast containing `"the first time speaking in this chapter"`.
  - On successful jump, emit clear feedback: `Speaker <DisplayName> — Box #X (k of N)`.
- **Rename While Pinned:** Renaming the active box's speaker while Pin is active MUST NOT overwrite `self._pinned_speaker_name`, allowing the translator to step cleanly to remaining occurrences of the original pinned speaker.
- **Unpin / Doc Switch:** Clear `self._pinned_speaker_name = None` on unpin or document switch/close.
- **Preserve Existing Behavior:** Keep `on_box_new()` prefilling the pinned speaker, and update `btn_pin_speaker` tooltip to clearly communicate both same-speaker `Next`/`Prev` navigation and New Box speaker prefill.
