- Q5 (7 Real Bugs/Traps Found in Raw `advscript.py` & `xuat2raw.py` — DO NOT PORT BLINDLY):
  1. **Escaped `\=` split bug (`advscript.py` `Store.load_file`):** `unesc()` supports `\=` -> `=`, yet flat-line parsing calls `line.split("=", 1)` instead of splitting on the first *unescaped* `=`. Any JP line containing `\=` is corrupted on import.
  2. **Block-mode hijack (`advscript.py` `Store.load_file`):** `block = any(l.startswith("=") for l in lines)` flips the ENTIRE dictionary file into multiline block mode if even one malformed/divider line begins with `=`. Must parse per-entry or detect block format strictly.
  3. **Silent global conflict memory bug (`advscript.py` `Store.resolve_conflict`):** Prompt says `'1a' = remember choice`, yet `self.resolutions[norm_k] = chosen.val` executes unconditionally on every pick!
     -> **Critical localization trap:** Re-using global-only memory for short context-dependent JP phrases (`はい`, `うん`, `えっ？`, `……`) recreates XUAT's global-collision problem inside Misora! Misora's dialog MUST distinguish:
        * `Use Once (this box)` (default!)
        * `Apply to Identical JP in This Story`
        * `Remember Globally` (explicit opt-in only)
  4. **Non-deterministic fuzzy truncation (`advscript.py` `Store._fuzzy`):** `for c in list(pool)[:4000]:` slices an unordered Python `set`. With 300k+ XUAT lines sharing common 3-char JP prefixes/suffixes, `len(pool)` exceeds 4,000, making fuzzy results random across runs and potentially dropping the true best match. Fix: deterministic ranking/sorting (e.g., by length proximity to query before capping) or trigram overlap scoring.
  5. **Completion gate misses untranslated speakers (`xuat2raw.py`):** `is_complete = (len(missing_real) == 0 and real_boxes_count > 0)` ignores `miss_names`, allowing stories with untranslated JP actor names to be marked 100% complete and repacked. Misora's completion meter should track dialogue AND speaker completion separately (or flag untranslated speakers clearly).
  6. **Unsafe single-story XUAT pruning & `conflict_manager` coupling (`advscript.py` `prompt_xuat_cleanup`):**
     * Imports `conflict_manager` (explicitly excluded by the user as irrelevant/bias).
     * More importantly, pruning a JP=EN line from XUAT as soon as Story A is repacked BREAKS translation for Story B (still unmigrated) if both share that phrase! Future pruning (v2) must only prune lines verified as unreferenced by remaining unmigrated stories, or exclude common/short lines.
  7. **NGUI tags & placeholder blind spot (`advscript.py` `norm2`):** `norm2` normalizes neither `{playername}`<->`{0}` nor NGUI rich-text tags (`[ff0000]`, `[-]`, `[b]`). In Misora, `core/xuat_index.py` should align normalization with `core/ngui_tags.py` and `core/search_engine.py` (while keeping exact raw-tag match highest priority).

PART 3 — NEW DESIGN SPECIFICATION: MTL DRAWER + LIVE TRANSLATION +
         MUTUAL EXCLUSION WITH "IMPORT FROM XUAT"
======================================================================

User Requirement:
- Replace/upgrade the unsatisfactory standalone MTL button experience.
- Place MTL inside the side drawer, as a tab alongside the existing `Reference` tab.
- Layout: Full-height `MTL Box` spanning the drawer panel, with a `Live Translation` checkbox.
- Redundancy guard: Opening the `Import from XUAT` window MUST automatically close the MTL drawer menu.

### 3.1 Proposed UX & Functional Design (Lean, Non-Overengineered)
1. **Drawer Tabs (`Reference` | `MTL`):**
   - Consolidate single-box MTL into the `MTL` tab inside the existing side drawer (keep `BatchTranslateDialog` separate for multi-box bulk runs).
   - **Top Bar (compact):** Active provider badge/dropdown (reusing existing `MTLEngine` config), `[ ] Live Translation` checkbox (default **OFF** on startup to protect user API quotas!), manual `Translate` / `Retry` button, and lightweight status text (`Idle` / `Translating...` / `Cached` / `Skipped (Punct)` / `Error`).
   - **Main Body (full-height):** Multi-line scrollable `MTL Box` spanning the panel height. Shows the translation of the active box's **original immutable JP text** (`get_jp_key(box_uid)`), with NGUI tags masked/unmasked via `core/ngui_tags.py`. Make it selectable/copyable (and optionally editable as a scratchpad before clicking Apply).
   - **Bottom Bar:** `Apply to Box` button (commits via central `_commit_widget_edit` with `source="mtl"`, respects Translation Lock -> disabled with `(Locked)` label when box is locked), `Copy` button, and optional `XUAT Hit` indicator badge (if `xuat_entries` index is loaded, shows instant free cache hit before hitting paid MTL!).

2. **Live Translation Behavior & Edge-Case Guards (Preventing Bugs & Quota Burn):**
   - **Trigger:** Fires ONLY on active box change (in Box View or Continuous View), tab switch to `MTL`, or toggling `Live Translation` ON — NEVER on user keystrokes while editing English text!
   - **Debounce (400 ms):** Rapid arrow-key navigation or scrolling cancels the previous timer so only the resting box triggers an API call.
   - **Stale-Response Drop:** Track `(doc_id, box_uid, request_seq)`. Worker posts result to the main-thread `queue.Queue` (Rule 15 — zero Tk calls from worker threads). If the user already moved to another box/file or closed the drawer, still store the result in the session cache, but DO NOT overwrite the visible `MTL Box`!
   - **Visibility Auto-Pause:** If the drawer is collapsed OR the user switches to the `Reference` tab, Live Translation automatically pauses (cancels pending debounce timer; zero background API calls while hidden).
   - **Zero-Value Skip Guard:** Do not auto-translate empty boxes, Box 0 metadata, punctuation-only strings (`……`, `！？`), or boxes where `jp_text` is already cached (instant cache display instead of network call).
   - **Error / Rate-Limit Backoff:** On HTTP 429 / auth failure, show error clearly in the MTL status bar and auto-uncheck (or pause) `Live Translation` with a toast/status notice so a broken API key doesn't spam errors on every box change!

3. **Auto-Close & Coupling Contract with `Import from XUAT`:**
   - When the user triggers `Import from XUAT`:
     1. Immediately close/collapse the side drawer (if open).
     2. Cancel any pending Live Translation debounce timer and mark active drawer requests stale so no background MTL update fires into the hidden drawer.
     3. Keep `Import from XUAT` as the single active translation/import workspace (no redundant dual-MTL surfaces).
   - **Shared Session MTL Cache (`core/mtl_engine.py` or app-level dict):**
     * Key: `(provider_id, model_or_target, normalized_jp_text)` -> `translated_text`.
     * Both the **MTL Drawer** and **`Import from XUAT`** read/write the same in-memory cache (bounded, e.g., LRU 2,000 entries). Translating a line in one surface makes it instant and free in the other!
   - **Debate Question on Re-Opening Behavior:**
     * While `Import from XUAT` is open (if non-modal), should clicking the drawer toggle be disabled (strict mutual exclusion) OR allowed only for `Reference` while blocking `MTL` live calls?
     * When `Import from XUAT` closes, should the drawer stay closed (clean, predictable) rather than popping back open unexpectedly? (Recommendation: stay closed; disable drawer MTL activation while `Import from XUAT` is open.)

### 3.2 Convenience Wins Identified During Brainstorm
- **1-Click "Apply & Next Box" shortcut** inside the MTL Drawer (`Ctrl+Enter` when focused in MTL Box, or dedicated small button) for fast keyboard-driven editing.
- **Speaker Name Mini-Hint** at top of MTL Box (e.g., `Speaker: Pecorine (ペコリーヌ)`) — gives context for pronouns/tone without wasting panel space, and optionally passes speaker context to LLM-based MTL providers if already supported by `mtl_engine.py`.
- **Clean Toolbar Simplification:** Clicking the existing MTL toolbar button (if retained) simply toggles open the side drawer directly to the `MTL` tab, instead of firing an opaque popup or clunky inline overwrite.
